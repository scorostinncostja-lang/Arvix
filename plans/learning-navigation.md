# Обучение и навигация по темам

Ветка codex/learning-navigation. Решение D64.

## Цель

Вкладку можно открыть без учебного блока. Результаты связываются с выбранной темой и доступны в последующих задачах.
Модель отвечает только на явный запрос разбора. Срок повторения виден сегодня и в утреннем брифе.
