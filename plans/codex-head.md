# Codex для учебного фокуса

Статус: адаптер готов к проверке. Ветка: codex/codex-head.

## Цель

Владелец может выбрать Codex по подписке ChatGPT для учебного фокуса. Общий диалог и фоновые сводки используют текущие роли Claude.

## Шаги

- [x] Отдельный адаптер CLI со структурированным ответом и запрещёнными инструментами оболочки.
- [x] Маршрут по роли learning и проверка обработки отказа.
- [x] Инструкция для серверной авторизации.
- [ ] Проверка ответа после подтверждения входа владельцем.

## Проверка

tests/test_codex_brain.py проверяет маршрутизацию, форму запроса и отказ.
На VPS проверить `codex login status` и выполнить один короткий учебный запрос через адаптер.
