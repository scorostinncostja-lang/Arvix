# Учебный фокус

Статус: готов к проверке PR. Ветка: codex/learning-focus.

## Цель

Из «Сегодня» ученик запускает учебную задачу и получает первое упражнение рядом с таймером.
Его попытка меняет следующий шаг. После возвращения к приложению занятие продолжается с сохранённого места.

## Решения и шаги

- [x] D63. Использовать действующий таймер, внешний источник упражнений и Obsidian.
- [x] Хранить шаг, уровень помощи и дату повторения в журнале. Отклонять устаревшие ответы.
- [x] Добавить экран занятия с текстовой попыткой, подсказкой, итогом и интерактивным примером для площади треугольника.
- [x] Проверить свёртку и конфликт двух фокусов в tests/test_learning_focus.py.

## Проверка

Открыть учебную задачу в приложении, начать фокус, изменить чертёж, запросить подсказку,
перезагрузить страницу, продолжить и решить свежий пример. Открыть каркас в Obsidian.
Автоматический тест проверяет, что ответ после подсказки требует ещё одной самостоятельной попытки.

## Прогресс и итог

Учебный режим доступен из задачи и карточки фокуса. Отдельный раздел не нужен.
Ход можно ввести текстом или надиктовать. Журнал хранит прогресс по нормализованному названию задачи.
