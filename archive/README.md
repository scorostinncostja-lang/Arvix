# Архив

## `v1-docker/` — прототип v1 (сентябрь–октябрь 2026)

Первая реализация по спецификации 1.0: FastAPI + aiogram в одном процессе, PostgreSQL 16 с pgvector, Redis,
APScheduler, Caddy, Alembic, роутер LLM на OpenAI-совместимом клиенте (Groq, Gemini, DeepSeek, OpenRouter, OpenAI),
React-TWA. Дошла до шагов 0.1–0.5 и 0.8–0.9 плана фазы 0.

**Не используется и не запускается.** Продукт — [`../arvix-claude/`](../arvix-claude/README.md). Почему стек
отложен — [`docs/09-DECISIONS.md`](../docs/09-DECISIONS.md), решение D1: один пользователь, Lite работает целиком
без зависимостей и без платы сверх подписки, а в прототипе аудит нашёл критические дефекты:

- `core/ai/providers/openai_compat.py` — `eval()` над аргументами инструментов от модели;
- `docker-compose.yml` — порты Postgres `5432` и Redis `6379` открыты наружу;
- `core/scheduler/jobs.py` — после утренней материализации напоминания на день не планировались.

Если когда-нибудь понадобится сервер с веб-приложением — начинать с исправления этих трёх пунктов.
Агентские правила `.clinerules/` относятся к этому стеку и тоже здесь: их правило «коммить и пушь сам» не действует.
