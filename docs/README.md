# ARVIX — Спецификация

> Персональный ИИ-ментор. Не чат-бот и не трекер привычек, а система, которая ведёт от цели к результату и держит дисциплину, пока ты не удержишь её сам.

**Версия:** 2.0 · **Дата ревизии:** 31.10.2026 · **Режим:** личное использование (single-user)
**Что изменилось в 2.0 и почему:** [12-DECISIONS.md](12-DECISIONS.md)

## Одним абзацем

Arvix — Telegram-бот с Web App, который знает твои цели, план недели и дня, состояние (сон, энергия) и заметки. Цель он раскладывает на результаты недели, результаты — на задачи с критерием готовности. Он проактивно напоминает, помогает начать, когда не начинается, принимает честный отчёт, проводит короткий вечерний разбор и раз в неделю — планирование. Учит по роадмапам с проверкой понимания и интервальными повторениями, помогает с языками, ищет актуальные источники в вебе и подключает внешние инструменты через MCP. Говорит прямо, без лести и без унижения. У прямоты есть выключатель, привязанный к сну и состоянию. Главная метрика — не сколько задач закрыто с ним, а насколько ты научился закрывать их без него.

## Четыре правила, которые нельзя нарушать

1. **Всё, что можно сделать кодом, делается кодом.** ИИ трогает только то, что требует понимания языка и суждения. Напоминания, метрики, режим Guard, долг, расписание повторений — детерминированный код.
2. **L2 никогда не стоит в цепочке ответа.** Тяжёлая аналитика идёт в фоне и пишет директивы в БД. Ответ в чате даёт одна быстрая модель.
3. **Результат выше активности.** Задача без критерия готовности — не задача. Метрика, которую можно накрутить без движения к цели, — не метрика.
4. **Арвикс отвечает за систему, ты — за исполнение и решения.** Бот показывает цену решения, но не запрещает. Любая фича, которая делает твою голову ненужной, спроектирована неправильно.

## Словарь

| Термин | Значение |
|---|---|
| **L0 / L1 / L2** | Рефлексы (код, без ИИ) / Голос (одна быстрая модель в чате) / Фон (тяжёлая аналитика по расписанию) |
| **TWA** | Telegram Web App — веб-интерфейс внутри Telegram |
| **DoD** | Definition of Done — критерий готовности задачи: что будет существовать, когда она сделана |
| **Результат недели** | 1–3 конкретных итога на неделю по каждой активной цели |
| **Опережающий показатель** | Регулярное действие под твоим контролем, которое двигает цель (часы практики, повторённые карточки) |
| **Долг** | Проваленная важная задача, которая не исчезает, пока по ней не принято решение |
| **Директива** | Вывод фонового аналитика с доказательствами из лога, который L1 читает как факт |
| **SRS / FSRS** | Интервальные повторения / алгоритм расписания повторений |
| **MCP** | Model Context Protocol — стандарт подключения внешних инструментов к ИИ |
| **Burnout Guard** | Детерминированный выключатель жёсткости: НОРМА / ЖЁЛТЫЙ / КРАСНЫЙ |
