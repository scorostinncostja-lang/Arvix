# 08 · Фазы реализации

## Принцип: работающее ядро раньше красивых фич

Главный риск проекта — не техническая сложность, а **смерть на архитектуре**. Три недели проектирования совета директоров, ноль работающих напоминаний, потеря интереса. Поэтому порядок фаз строго такой: сначала то, что даёт пользу с первого дня.

**Критерий перехода к следующей фазе: предыдущая работает на тебе минимум 7 дней подряд.** Не «код написан» — «я этим пользуюсь неделю».

---

## Фаза 0 · Ядро (2–3 недели)

**Цель:** к концу фазы Арвикс уже реально держит твой день.

| Блок | Содержание |
|---|---|
| Инфраструктура | Docker Compose, Postgres + pgvector, Redis, Caddy, деплой на VPS, `.env`, миграции |
| БД | Event Log, tasks, profile, goals, проекции, базовые инварианты |
| Бот | aiogram 3, `/start`, онбординг Стадия 1, команды `/day`, `/done`, `/add`, `/status` |
| Планировщик | APScheduler, шаблоны дней, материализация задач, напоминания T-5 / T+0 / T+конец |
| Подтверждение | Кнопки ✅/⚠️/❌, `confirm` и `report`, запись событий |
| TWA v1 | Дашборд + недельная сетка задач с drag-n-drop, валидация initData |
| Realtime | WebSocket-хаб, Redis pub/sub, синхронизация чат ↔ TWA |
| L1 | Абстракция `LLMProvider`, Groq + fallback, конституция v1, контекст-пакет, 4 инструмента |
| Ритуалы | Утренний брифинг, вечерний разбор (без Analyst — по шаблону + одна модель) |

**Готово, когда:** 7 дней подряд Арвикс будит, напоминает, спрашивает, закрывает задачи, и вечером ты отвечаешь на разбор. TWA и чат показывают одно и то же без обновления страницы.

**Чего в фазе 0 НЕТ:** XP, HP, совет моделей, Obsidian, ESP32, биометрия, финансы. Только цикл «план → напоминание → отчёт».

## Фаза 1 · Характер и механики (2 недели)

| Блок | Содержание |
|---|---|
| Голос | Few-shot (8 примеров), тон-блоки, валидаторы ответа |
| Burnout Guard | 4 режима, расчёт из ручного ввода сна, подмена тон-блока, тесты |
| Safety-контур | Детекция, `mentor_enabled`, переключатель в TWA, тесты |

| Долг | Очередь, блокировка необязательных дел, эскалация |
| Ручная биометрия | Утренний ввод, `/sleep`, влияние на план |
| Профиль | Интервью Стадия 2 — Арвикс добирает профиль в диалоге |
| Память | `memory_facts`, инструмент `remember`, векторный отбор в контекст |
| Протокол игнора | Эскалация, заморозка, протокол возвращения |
| Бюджет и типы дней | Недельный бюджет, 5 типов дней, прогрессия |

**Готово, когда:** ты чувствуешь характер, а не шаблон. Режимы переключаются и это заметно. Штрафы ощутимы, но не убивают мотивацию.

## Общая оценка

| Фаза | Срок | Накопительно |
|---|---|---|
| 0 · Ядро | 2–3 нед | 3 нед |
| 1 · Характер | 2 нед | 5 нед |
| 2 · Мозг | 2 нед | 7 нед |
| 3 · Совет | 1–2 нед | 9 нед |
| 4 · Железо | 2 нед | 11 нед |
| 5 · Тело и деньги | 3 нед | 14 нед |

Сроки даны с учётом твоей реальной загрузки (колледж + смены пт-вс), то есть ~15-20 часов в неделю на проект. Это примерно **3.5 месяца до полной системы** и **3 недели до первой пользы**.

## Что делать, если застрял

| Симптом | Действие |
|---|---|
| Фаза 0 идёт больше 4 недель | Выкинуть TWA-сетку, оставить список задач. Вернуться к сетке позже |
| Не заходит интеграция (Huawei, Obsidian) | Таймбокс 1 день. Не получилось — включить fallback и идти дальше |
| Механика наказаний бесит | Не терпеть. Уменьшить урон вдвое, добавить щитов. Система под тебя, не наоборот |
| Пропал интерес | Это сигнал, что фаза слишком длинная. Найти, что можно выпустить за 2 дня, и выпустить |
| Арвикс звучит не так | Править **few-shot**, не конституцию. Конституция меняется редко |
