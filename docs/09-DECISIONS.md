# 09 · Журнал решений (ревизии 0.3–0.4, 14–17.11.2026)

> Что изменено, что убрано, что исправлено — и почему. Любое решение можно откатить: для этого записана причина
> и место в коде.

## 1. Главный вывод аудита

Ядро идеи сильное: внешний контур дисциплины, «всё, что можно, — кодом», журнал событий, Burnout Guard, совет
не в цепочке ответа. Работающий продукт — Arvix Lite — его честно реализует. Но у проекта было четыре болезни:

1. **Смерть на архитектуре.** С сентября по ноябрь — четыре направления: Docker-прототип v1 (`main`), Docker v2
   (ветка `claude/arvix-v2-phase-0-*`), спецификация 2.0 (PR #1), Lite с сервером (PR #2–#5). Ни одна неделя
   ежедневного использования. Самый ценный следующий шаг — не фича, а неделя жизни с тем, что уже есть (R0).
2. **Спецификация описывала мечту, а не систему.** `docs/` рассказывали про Postgres, pgvector, Redis, TWA,
   WebSocket, ESP32-сервер, шесть моделей и Huawei-мост; работает SQLite + `claude -p` + Telegram + Claude Code.
   Корневой README и CLAUDE.md учили агентов `make up` для стека, который не используется. Теперь спецификация
   написана по коду, со статусами ✅ 🧪 📋 ❌.
3. **Код местами нарушал собственные принципы.** В 🟥 бот продолжал напоминать о всех задачах; школа становилась
   задачей с отчётом и штрафом; после восьми дней молчания протокол игнора начинался заново со штрафами. Исправлено
   (§4).
4. **Слабое звено «цель → день».** Нет критерия готовности у задач, нет протокола «не могу начать», недельное
   планирование только в Claude Code. Это следующие пункты дорожной карты (R1–R3), а не новые подсистемы.

## 5. Известные ограничения (честно)

- **0.4 не проверена с настоящей головой:** действия интерфейса, `<recall>`, приветствие, любопытство и поиск в сети
  проверены тестами на подставной модели (196 тестов). Как часто модель выбирает правильное действие — покажет неделя.
- **sslip.io** — общий домен: у Let's Encrypt лимит сертификатов на домен в неделю, и он может быть исчерпан чужими
  выпусками. Тогда — свой бесплатный поддомен (DuckDNS) через `ARVIX_WEB_HOST=… deploy/web-setup.sh`.
- **WebAPK собирает только Chrome** (и браузеры на его основе). В других браузерах «На экран Домой» даёт ярлык PWA.
- **Терминал** — curses: Linux и macOS; эмодзи в терминале убраны (ширина у терминалов разная).

- **Голова и планировщик в одном потоке.** Пока голова думает (до 180 с), тик планировщика ждёт: напоминание может
  опоздать на эти минуты.
- **История диалога — 10 последних сообщений**, без сжатия старых.
- **Голова видит всё хранилище** (если `vault_tools = true`), маскирования секретов нет — R5.
- **rsync-синхронизация:** удаления не переносятся, окно конфликта 2 минуты — R9.
- **Бэкап сервера** по cron ставится вручную; в локальном режиме автоматического бэкапа нет.
- **Валидатор мягкого режима** работает по стоп-словам: бытовое «долг» или «провал» в 🟥 тоже вызовет перегенерацию,
  а при повторе — шаблонный ответ.
- **Три «всегда» факта памяти** — самые старые из тем «цель, страх, слабость, триггер», а не самые свежие.
- **Панель дня и таймер правятся не чаще тика** (≤ 20 с), а пока голова думает (до 180 с), ждут вместе с планировщиком.
- **Сезон и ранг** ни на что не влияют — Q1.
- **Фото-отчёт** принимается без проверки — сознательно (D10).
