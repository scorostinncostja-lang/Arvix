# 05 · Интерфейсы

## 1. Разделение ролей

| Канал | Для чего | Правило |
|---|---|---|
| **Telegram** | День: брифинг, напоминания, кнопки, отчёты, сон, траты, просьбы изменить план, разбор | Короткое, проактивное, с телефона. Всё, что решается одной фразой или кнопкой |
| **Claude Code** (дом `~/Arvix`) | Планирование недели, цели и этапы, роадмапы, учёба, работа с Obsidian, ретро, знакомство | Длинное и вдумчивое: таблицы, файлы, несколько шагов подряд |
| **CLI `arvix`** | Всё без ИИ: отчёты, статус, интервью в терминале, настройка, проверка, отладка | Работает, даже когда подписка исчерпана |
| **Чат Claude Desktop** | Те же 12 инструментов, без скиллов и хуков | Разговор с Арвиксом в обычном окне чата |
| **claude.ai** | Голос и методика без доступа к журналу | Цифр состояния нет — Арвикс их не выдумывает |

Единственный источник правды — журнал событий. Каналы не синхронизируются между собой, они читают одно и то же.

## 2. Telegram

### 2.1. Команды

| Команда | Действие |
|---|---|
| `/start` | знакомство, если ядро интервью не пройдено; иначе брифинг |
| `/help` | список команд и примеры свободного текста |
| `/day [дата]` | задачи дня с id, выполнение, глубокая работа |
| `/week` | неделя: своё время против бюджета, глубокая работа, квоты, траты |
| `/status` | режим и причина, уровень, XP, HP, стрик, сезон, щиты, автономность |
| `/done <id или часть названия> [что сделано]` | закрыть задачу: `/done физ решил 10 задач` |
| `/add <текст>` | задача без модели: `/add Физика 18:00 60м !4 deep завтра` — время, длительность, важность, глубокая работа, дата |
| `/sleep 7:30 [00:10]` | сон и время отбоя |
| `/spend 1200 еда [!]` | трата, `!` — импульсивная |
| `/note <текст>` | мысль в Inbox хранилища |
| `/find <запрос>` | поиск по Obsidian |
| `/focus [минуты]` | фокус-сессия (по умолчанию 25); в конце — «Без прерываний?» |
| `/reason <причина>` | причина плохого дня — для щита |
| `/schedule [пожелания]` · `/schedule show` | собрать или поправить распорядок недели · показать текущий |
| `/goals` | дерево целей и этапов |
| `/debrief` | разбор прямо сейчас |
| `/answer` | следующий учебный вопрос — с готовым ответом (пишется в журнал) |
| `/onboard` · `/skip` · `/pause` | знакомство: продолжить · пропустить вопрос · пауза |
| `/silent` | тихий день |
| `/sos` · `/sos off` | ручной 🟥 на 24 часа · снять |
| `/mentor on` · `/mentor off` · `/mentor` | включить · выключить · показать состояние |
| `/export` | всё в Obsidian |

Остальное — обычным текстом: «английский сделал, 30 карточек», «спал 6 часов, лёг в час», «потратил 900 на
доставку, импульсивно», «можно я в 18:00 в зал вместо английского?», «запиши мысль: …», учебный вопрос.

### 2.2. Кнопки (L0, без модели)

| Где | Кнопки | Что делает код |
|---|---|---|
| T−5 | **Начать сейчас** · **Отложить 15** · **Не смогу** | `task_started` · `task_deferred(+15)` · провал → «Что помешало?» |
| конец задачи | **✅ Да** · **⚠️ Частично** · **❌ Нет** | `confirm` закрывает сразу; `report`/`photo` — ждёт фразу или фото · «Сколько процентов и что помешало?» · провал, HP, долг для 4–5 → «Что помешало?» |
| вопрос интервью | **Пропустить** | `interview_skipped`, следующий вопрос |
| конец блока интервью | **Дальше** · **Пауза** | следующий блок · пауза |
| предложение распорядка | **✅ Сохранить** · **✏️ Поправить** | шаблоны в журнал · ждёт правку словами и пересобирает |
| конец фокус-сессии | **✅ Да** · **⚠️ Прерывали** | `focus_session(минуты)` · половина минут |

### 2.3. Чего бот ждёт после вопроса

После некоторых сообщений следующий текст человека — ответ, а не новая тема (`runtime.tg_await`):
отчёт по задаче, процент частичного выполнения, причина провала, ответ на разбор, правка распорядка, сон после
брифинга («7:20»), ответ на вопрос интервью. Сообщение, отправленное **раньше** вопроса (очередь после обрыва сети),
ответом не считается.

### 2.4. Как выглядят сообщения

Брифинг (код, без модели):
```
☀️ 07:45 · Четверг · Учебный день

Режим 🟨 ЖЁЛТЫЙ — сон <6ч 2 дня подряд.
Вчера: 3 из 4, глубокая 45м.

Сегодня 3:
1. 16:00 Математика ОГЭ: задания 20–25 (65 мин)
2. 18:30 Физика: §12 Перышкин + 5 задач (30 мин)
3. 20:00 Зал (30 мин)
Квоты недели: спорт 1/3 · социум 0/2 · новое 0/1 · отдых без экрана 0/3
Отбой сегодня в 23:00. Не обсуждается.
```

Напоминание и проверка:
```
⏱ Через 5 мин: Математика ОГЭ: задания 20–25 · 65 мин     [Начать сейчас] [Отложить 15] [Не смогу]
▶️ Блок пошёл: Математика ОГЭ: задания 20–25. 65 минут. Телефон — убрать.
Сделано: Математика ОГЭ: задания 20–25?                    [✅ Да] [⚠️ Частично] [❌ Нет]
```

Разбор (факты — код, оценка и вопросы — модель):
```
🌙 Разбор

Сделано: 2 из 3. Глубокая 1ч05м из 1ч05м.
Сон 5ч50м.
Квоты: спорт 1/3 · социум 0/2 · новое 0/1 · отдых без экрана 0/3

Задачи закрыты, но третью ночь меньше шести часов — день держится на запасе, которого нет.

Два вопроса:
1. Что держит тебя после 23:00 — задачи или телефон?
2. Физику закрыл за 30 минут: §12 понятен или пролистан?
Ответь одним сообщением.
```

В 🟥 вместо всего этого — мягкий брифинг без плана, мягкий отбой и вопрос «Как ты сегодня? Одной фразой, без цифр».
Полное расписание сообщений — [02-MECHANICS.md §12](02-MECHANICS.md#12-суточный-цикл-расписание-бота-конфиг-schedule).

### 2.5. Ответ модели
Под ответом головы код дописывает, что реально записано: `✅ Английский +11 XP · сон 7ч20м`, и что отказано:
`⚠️ Не выполнено: complete_task: Задача «химия» не найдена`. Модель не пишет числа XP и HP сама — их у неё нет.

## 3. Claude Code

### 3.1. Дом Арвикса
`~/Arvix` (создаёт `arvix setup` или `arvix init-home`):
- `.arvix-home` — маркер: хуки плагина работают только здесь;
- `.claude/settings.json` — стиль `arvix:Arvix`, строка состояния, разрешения: инструменты `mcp__plugin_arvix_arvix`,
  Grep, Glob, чтение хранилища; хранилище добавлено как рабочая папка;
- `CLAUDE.md` — короткая памятка для сессии.

Запуск: `cd ~/Arvix && claude` (или вкладка Code в Claude Desktop → папка `~/Arvix`). При первом запуске ответить
«да» на доверие папке — иначе разрешения не включатся. Вне дома скиллы и инструменты тоже доступны, но хук молчит.

### 3.2. Что подкладывает плагин
- **Стиль** — конституция, правила инструментов, мягкие примеры (генерируется из `arvix/constitution/`).
- **SessionStart** — состояние: тон-блок режима, контекст-пакет; вне мягкого режима — правило решений и жёсткие
  примеры; при пустом профиле — `<first_session>`: Арвикс сам начинает знакомство.
- **UserPromptSubmit** — строка `Арвикс · сейчас чт 12.11 16:32 · режим 🟩 НОРМА · HP 100 · сегодня 1/3`; при смене
  режима посреди сессии — новый тон-блок.
- **Строка состояния** — `🟩 НОРМА · ур.3 · HP 92 · сегодня 1/3 · → 18:30 Физика: §12 Перышкин · ctx 7%`;
  в 🟥 — `🟥 КРАСНЫЙ · без цифр и задач`. В удалённом режиме кэшируется на минуту.

### 3.3. Скиллы

| Скилл | Когда |
|---|---|
| `arvix` | всё повседневное: отчёты, сон, траты, «хочу погулять в 15:00», вопросы про день, HP, долг, режим, усталость |
| `onboarding` | знакомство и настройка: прочитать хранилище, оставшиеся вопросы, распорядок, цели, роадмапы, шаблон отчёта, нагрузка |
| `brief` | утро: брифинг и план дня |
| `debrief` | вечер: разбор — факты, оценка, 2 вопроса, вывод, план завтра |
| `plan` | неделя: свободные окна, бюджет, долг, квоты, этапы цели → задачи по дням и шаблоны |
| `goal` | цель → этапы с датами и метриками → роадмап → блоки в плане; «как я иду к цели?» |
| `learn` | учёба: сократовский режим, роадмапы, чекпоинт «объясни своими словами» |
| `notes` | Obsidian: поиск, выжимки по своим заметкам, каркас конспекта, Inbox, экспорт |
| `retro` | ретро недели или месяца: паттерны с доказательствами → директивы |

Вызывать явно не обязательно: «собери мне день», «найди в заметках про производные» — Claude подберёт скилл сам.

### 3.4. MCP-инструменты (12)

| Инструмент | Действия |
|---|---|
| `context` | контекст-пакет — вызывать первым |
| `day` | задачи на дату с id и метриками |
| `task` | `add` · `complete` (report, done_pct) · `fail` (reason) · `defer` (minutes) · `cancel` (reason) · `start` · `write_off` (обоснование) |
| `log` | `sleep` · `expense` · `social` · `focus` · `reason` |
| `profile` | `get` · `set` · `goal` · `goals` · `trait` · `remember` · `forget` · `template` |
| `interview` | `status` · `next` · `answer` · `skip` · `reset` |
| `check_request` | факты для просьбы изменить план: выполнение, глубокая работа, долг, режим, конфликты с задачами и обязательным, квоты |
| `debrief` | `facts` · `complete` |
| `analyst` | `events` (сырая лента с id) · `directive` (только с evidence) · `insight` |
| `notes` | `overview` · `paths` · `search` · `read` · `write` · `block` · `inbox` · `daily` · `daily_sync` |
| `mode` | `status` · `sos_on` · `sos_off` · `silent` · `safety_flag` |
| `export` | полный экспорт в Obsidian |

Включить ментора обратно инструментом нельзя — только человек командой.

## 4. CLI `arvix` (без ИИ)

| Команда | Что делает |
|---|---|
| `arvix status` · `arvix day [дата]` · `arvix context` | состояние · задачи · что видит модель |
| `arvix add "Физика" --start 18:00 --dur 60 --imp 4 --sphere learning --deep [--date …]` | задача |
| `arvix done <id> [--report "…"] [--pct 60]` · `arvix fail <id> --reason "…"` · `arvix defer <id> [30]` | работа с задачами |
| `arvix sleep 7:20 [--bed 00:10] [--date …]` · `arvix spend 450 еда [--impulse]` | сон, траты |
| `arvix note "…"` · `arvix find …` · `arvix export [--days 60]` | Obsidian |
| `arvix interview [--block study]` | знакомство в терминале: Enter — пропуск, Ctrl+C — пауза |
| `arvix mentor on|off` · `arvix sos on|off` · `arvix silent` | режимы |
| `arvix events [--days 3]` · `arvix rebuild` | лента событий · проверка инвариантов журнала |
| `arvix setup [--vault … --tz … --home … --telegram/--no-telegram --yes]` | настройка; без флагов — диалог |
| `arvix init-home` · `arvix doctor` · `arvix desktop-mcp` | дом для Claude Code · проверка установки · чат Claude Desktop |
| `arvix statusline` | строка состояния (её зовёт Claude Code) |
| `arvix remote show` · `arvix remote set arvix@HOST` · `arvix remote off` | удалённый режим |
| `arvix brain-test "текст"` | пробный вызов головы (тратит лимит) |
| `arvix telegram` · `arvix mcp` · `arvix hook <событие>` | бот, MCP-сервер, хуки — их зовут systemd и Claude Code |

В удалённом режиме все команды, кроме `setup`, `init-home`, `doctor` и `desktop-mcp`, выполняются на сервере по SSH.

## 5. Claude Desktop и claude.ai

- **Чат Claude Desktop:** `arvix desktop-mcp` добавляет MCP-сервер в `~/.config/Claude/claude_desktop_config.json`
  (старый файл сохраняется рядом с суффиксом `.bak-…`). После перезапуска приложения — те же 12 инструментов.
- **claude.ai:** проект «Арвикс», в инструкции — `arvix-claude/deploy/claude-ai/PROJECT_INSTRUCTIONS.md`, скилл —
  `arvix-skill.zip` в Settings → Capabilities → Skills. Журнала, XP/HP и Obsidian там нет; блок `<stateless>`
  запрещает выдумывать цифры состояния. С телефона полноценный Арвикс — Telegram-бот.

## 6. Знакомство (онбординг)

### 6.1. Устройство
Статичный банк из **52 вопросов в 10 блоках** (`arvix/interview.py`). Порядок задаёт код, страхи — последними:
сначала доверие.

| Блок | Вопросов | Зачем |
|---|---|---|
| Ядро | 7 | имя, род обращения, город и часовой пояс, сон (реальный и целевой), расписание недели, главная цель и «зачем» |
| Учёба | 8 | главные предметы, уровень, экзамены, что дальше, инструменты, метод занятия, где застревает, сколько часов потянет |
| Направление | 6 | мечты, «хочу», нагрузка, проекты, критерий успеха через 3 месяца, профессии |
| Распорядок дня | 6 | будний и выходной день по часам, что нельзя двигать, свободные окна, отдых, признаки перегруза |
| Тело и энергия | 4 | спорт, рост и вес, пики энергии, еда |
| Привычки | 5 | хорошие, вредные, триггеры срыва, экранное время, что уже пробовал |
| Как ты работаешь | 5 | фокус, момент ухода в телефон, что мотивирует, граница жёсткости, как лучше учится |
| Деньги | 3 | доход, траты, цель накопления |
| Люди | 3 | кто важен, живые встречи, **кому написать, если станет плохо** (контакт safety-контура) |
| Слабости и страхи | 5 | где проигрывает себе, о чём врёт себе, страхи, что после провала, идеальный ментор |

Полный текст вопросов — [`arvix-claude/GUIDE.md` §5](../arvix-claude/GUIDE.md#5-знакомство-все-52-вопроса).

### 6.2. Что разбирает код, а что модель
- **Код** (`interview.extract`): имя, род («сделала» → женский), город → часовой пояс (~35 городов СНГ или явное
  `Area/City`), четыре времени сна, главная цель и «зачем» → цель `main`, контакт поддержки, недельные часы учёбы
  (берётся **меньшая** из названных цифр).
- **Модель** — один вызов на блок (`EXTRACT_SCHEMA`): свободные ответы → цели, черты, факты, поля профиля.
- После блока «Распорядок дня» — предложение распорядка недели (`TEMPLATES_SCHEMA`) с кнопками «Сохранить / Поправить».
  Без шаблонов дней нет ни задач, ни напоминаний.

### 6.3. Где проходить
Telegram (`/start`, `/onboard`), Claude Code (`/arvix:onboarding` или сама первая сессия), терминал
(`arvix interview`). Прогресс общий. В Claude Code Арвикс **сначала читает хранилище** и не спрашивает то, что уже
написано, а подтверждает: «В заметках подъём 7:00 — это ещё так?». Полезный минимум — «Ядро» и «Распорядок дня»;
остальное честнее по блоку за вечер. Профиль никогда не «готов»: раз в месяц в ретро — проверка, актуальны ли цели
и страхи.
