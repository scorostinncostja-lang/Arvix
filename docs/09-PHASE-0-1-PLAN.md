## Порядок работы с ИИ-агентом

1. Постоянный контекст — `CLAUDE.md` в корне: правила + ссылки на `docs/README.md`, `00-VISION.md`, `01-ARCHITECTURE.md`
2. **Один шаг за сессию.** Шаг = один коммит. Не давать агенту писать сразу фазу: контекст переполнится, качество упадёт
3. Перед шагом — агент читает разделы, указанные в шаге («Читать: …»)
