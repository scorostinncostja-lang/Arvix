# 10 · Сборка умного таймера ESP32 — инженерная часть

> Дополняет `06-IOT-BIOMETRICS.md`. Здесь — конкретные детали для покупки и паяльника: BOM с моделями, схема подключения, питание, корпус, порядок сборки и прошивка.

## 1. Спецификация модуля (что и почему)

| Требование | Решение |
|---|---|
| Работает без телефона | Автономный старт таймера с клавиатуры |
| Видно фазу издалека | RGB-индикатор (WS2812) |
| Слышно окончание | Пассивный зуммер — свет не разбудит внимание, звук разбудит |
| Быстрый ввод чисел | Матричная клавиатура 4×4 |
| Читаемое состояние | OLED 128×64 |
| Мгновенный "стоп всего" | Отдельная физическая кнопка, не через матрицу |
| Не виснет без Wi-Fi | Локальная стейт-машина + буфер событий в NVS |

### 2.1. Вариант «ESP32 + встроенный OLED»
Готовые платы «ESP32 + OLED 0.96" на борту» экономят место, но дисплей на них обычно подключён к **GPIO 4 (SDA) / GPIO 15 (SCL)**, а не к 21/22 — это меняет распиновку из §3. Решение: либо брать отдельный OLED-модуль (гибче, распиновка ниже верна как есть), либо адаптировать `include/config.h` под пины конкретной платы (одна строка).

## 3. Распиновка — финальная

ESP32-S NodeMCU-32S, 30-контактная плата (широкая, DevKit v1 layout).

```
Функция              GPIO      Примечание
────────────────────────────────────────────────────────
OLED SDA              21       I2C data
OLED SCL              22       I2C clock
Клавиатура ряд 1      13
Клавиатура ряд 2      12       ⚠️ GPIO12 — strapping pin (MTDI).
Клавиатура ряд 3      14           Не должен быть HIGH при старте.
Клавиатура ряд 4      27           В прошивке — INPUT_PULLUP, ок.
Клавиатура кол. 1     26
Клавиатура кол. 2     25
Клавиатура кол. 3     33
Клавиатура кол. 4     32
WS2812 DIN             4
Зуммер (через транз.) 18
Кнопка "СТОП"          19       INPUT_PULLUP, кнопка на GND
Статус-LED (встр.)     2        встроенный синий LED платы — heartbeat
────────────────────────────────────────────────────────
Питание OLED/WS2812   3V3 или 5V — смотри §4
```

**Запрещённые/особые пины (не трогать):**
- `GPIO 6–11` — заняты встроенной SPI-флешкой, использование ломает загрузку
- `GPIO 34–39` — только вход, без internal pull-up/down, не годятся для клавиатуры/кнопки с pull-up
- `GPIO 0, 2, 15` — strapping-пины загрузки. GPIO2 занят под статус-LED — это безопасно (плата это и так делает по умолчанию), но не вешать на него что-то, что может быть HIGH при холодном старте
- `GPIO 12` — strapping (MTDI), задаёт напряжение флеша при старте. Использование как **вход** с pull-up безопасно (наш случай — ряд клавиатуры), но никогда не подключать сюда что-то, что тянет пин в HIGH во время сброса

## 4. Схема подключения

### 4.1. Питание
```
USB-C 5V ──┬──────────────────────────────┐
           │                              │
      [ESP32 5V/VIN]                 [WS2812 VCC]
           │                              │
      (стабилизатор на плате)        100мкФ электролит
           │                         между VCC и GND WS2812
      [3V3 из ESP32] ── OLED VCC
           │
          GND ─── общий для ВСЕХ модулей (OLED, клавиатура, WS2812, зуммер, кнопка)
```
OLED питается от 3V3 (штатно для SSD1306-модулей с логикой 3.3V). WS2812 и зуммер — от 5V (VIN/5V пин платы), потому что WS2812 на 3.3V данных иногда работает нестабильно на длинных проводах; при коротких проводах (<10см) можно и от 3V3 — сигнал DIN всё равно проходит по спецификации WS2812B от 3.3V логики в большинстве плат.

### 4.2. OLED (I2C)
```
SSD1306        ESP32
VCC     ────   3V3
GND     ────   GND
SCL     ────   GPIO22
SDA     ────   GPIO21
```
Адрес по умолчанию `0x3C` (реже `0x3D` — проверить I2C-сканером при первом включении, код прошивки это делает автоматически).

### 4.3. Матричная клавиатура 4×4
Шлейф 8 проводов, ряды и столбцы — без фиксированной полярности, но при неправильном порядке клавиши будут "перепутаны" (лечится в `config.h` перестановкой массивов, перепайка не нужна).
```
Клавиатура pin 1 (R1) ── GPIO13
Клавиатура pin 2 (R2) ── GPIO12
Клавиатура pin 3 (R3) ── GPIO14
Клавиатура pin 4 (R4) ── GPIO27
Клавиатура pin 5 (C1) ── GPIO26
Клавиатура pin 6 (C2) ── GPIO25
Клавиатура pin 7 (C3) ── GPIO33
Клавиатура pin 8 (C4) ── GPIO32
```
Внешние резисторы не нужны — библиотека `Keypad` использует внутренние pull-up программно.

### 4.4. WS2812 (адресный RGB)
```
WS2812   VCC ── 5V (или 3V3, см. §4.1)
WS2812   GND ── GND
WS2812   DIN ── GPIO4      (через резистор 330-470 Ом последовательно — защита от помех, опционально)
                            между VCC и GND WS2812 — конденсатор 100мкФ
```

### 4.5. Зуммер (пассивный, через транзистор)
Пассивный зуммер нельзя вешать напрямую на слабый GPIO для громкого звука — берём транзисторный ключ:
```
GPIO18 ──[220 Ом]── База (B) транзистора 2N2222/S8050
Эмиттер (E) ── GND
Коллектор (C) ── (–) зуммера
(+) зуммера ── 5V
```
GPIO18 генерирует PWM-тон (`tone()`/`ledc`), транзистор коммутирует ток зуммера — GPIO не перегружается.

### 4.6. Кнопка "СТОП/паника"
```
Кнопка нога 1 ── GPIO19
Кнопка нога 2 ── GND
```
`INPUT_PULLUP` в коде: нажатие = LOW. Внешний резистор не нужен.

## 5. Бюджет питания (проверка, что БП хватает)

| Потребитель | Ток (тип.) | Ток (пик) |
|---|---|---|
| ESP32 (Wi-Fi активен, TX) | 120–180 мА | до 500 мА (короткие пики при TX) |
| OLED SSD1306 | 15–20 мА | — |
| WS2812 (1 шт., белый максимум) | 20 мА | 60 мА |
| Зуммер + транзистор | 20–30 мА | 30 мА |
| Клавиатура | ~0 (пассивная матрица) | — |
| **Итого** | **~180–230 мА** | **до ~620 мА** |

БП на 5V/2A (2000 мА) даёт запас ×3 — стандартная зарядка телефона подходит без вопросов. Важно: USB-кабель должен быть с толстыми проводами питания (не самый тонкий "зарядный только" кабель) — на пиках Wi-Fi TX просадка напряжения на тонком кабеле — частая причина рестартов ESP32.

## 6. Порядок сборки

1. **Макет на breadboard.** Собрать всё без пайки, проверить каждый модуль по отдельности (шаги теста — §8) перед тем как паять.
2. **I2C-скан.** Первым делом — прошить только сканер шины (в стартовом коде это делается автоматически при первом включении, см. README прошивки), убедиться что OLED виден по адресу `0x3C`.
3. **Клавиатура.** Проверить каждую клавишу через Serial Monitor — коды должны совпадать с раскладкой в §3 из `06-IOT-BIOMETRICS.md`.
4. **WS2812.** Проверить все три базовых цвета отдельно — паразитные наводки от соседних проводов на данных WS2812 — частая причина "мерцания", лечится резистором 330 Ом на DIN и конденсатором на питании.
5. **Зуммер.** Проверить тон на разных частотах — писк вместо чистого тона означает, что зуммер активный (со встроенным генератором), а не пассивный — тогда транзистор не нужен, просто HIGH/LOW.
6. **Перенос на перфоплату.** Только после того, как всё работает на макете. Паять в порядке: сначала земляная шина (общий GND — самая частая ошибка при пайке — забытая перемычка GND между модулями), потом питание, потом сигнальные линии.
7. **Прожиг 24 часа.** Оставить включённым сутки в режиме постоянного Wi-Fi перед тем как класть в корпус — ловит нестабильные пайки и БП.
8. **Корпус.** Прорези под OLED, клавиатуру, кнопку, вентиляцию (ESP32 при долгой работе Wi-Fi заметно тёплый), отверстие USB-C сбоку.

## 7. Корпус — ориентировочные размеры

Для 3D-печати (или как ТЗ для готового корпуса):
```
Габариты:      110 × 70 × 35 мм
Окно OLED:     30 × 15 мм, по центру верхней панели, глубина посадки 3мм
Окно клавиатуры: 55 × 55 мм, ниже OLED
Кнопка СТОП:   отдельное отверстие Ø13мм, в стороне от клавиатуры — чтобы не путать в панике
Отверстие WS2812: Ø5мм рассеивающий колпачок или полупрозрачная вставка — сверху корпуса, видно с любого угла комнаты
USB-C:         прорезь 10×4мм на боковой стенке, совпадает с разъёмом платы
Вентиляция:    4-6 отверстий Ø2мм на задней стенке над ESP32
```

## 8. Чек-лист бринг-апа (перед тем как класть в корпус)

- [ ] Плата видна в Arduino IDE/PlatformIO по правильному COM-порту
- [ ] `i2c_scan` при старте находит OLED на `0x3C`
- [ ] Текст и время рисуются на OLED без артефактов
- [ ] Все 16 клавиш дают уникальный, ожидаемый код в Serial Monitor
- [ ] WS2812 переключается между красным/зелёным/синим/жёлтым/фиолетовым без мерцания
- [ ] Зуммер даёт чистый тон на пробном сигнале `beep(ok)`
- [ ] Кнопка "СТОП" читается как LOW при нажатии, HIGH в покое
- [ ] Портал настройки Wi-Fi (WiFiManager) поднимается при первом включении и при удержании кнопки СТОП при старте
- [ ] После настройки Wi-Fi устройство подключается к серверу по WebSocket, шлёт `hello`
- [ ] При обрыве Wi-Fi таймер продолжает считать локально, индикатор жёлтый
- [ ] При восстановлении Wi-Fi буфер событий из NVS дозаписывается на сервер
- [ ] Долгое замыкание USB-питания (проверка кабеля) не роняет плату в бутлуп

Прошивка и структура кода — в `firmware/arvix-timer/README.md`.
