# 05 · Бот и Telegram Web App

## 1. Разделение ролей

| Канал | Для чего |
|---|---|
| **Чат бота** | Проактив, короткие решения, отчёты, разговор, изменение плана голосом |
| **TWA** | Сложный ввод, визуализация, всё, что неудобно текстом |

Правило: **если это можно сказать одной фразой — это чат. Если это форма, таблица или график — это TWA.**

## 2. Онбординг

### Проблема исходного плана
Форма на 15 полей на первом экране = отвал. Плюс страхи, слабости и вредные привычки формой не собираются — человек пишет «прокрастинация» и уходит.

### Решение: три стадии

**Стадия 1 — Ядро (2 минуты, форма в TWA).** Только то, без чего система не запустится:
1. Имя
2. Дата рождения
3. Город
4. Целевое время отхода ко сну и подъёма
5. Дни занятости (учёба / смены) — сетка часов
6. Одна главная цель на ближайший год + одна фраза «зачем»

→ **Система уже работает.** Первое расписание, первые напоминания, первый вечерний разбор.

**Стадия 2 — Интервью (2 недели, по 1-2 вопроса в день в чате).** Арвикс сам добирает профиль, вплетая вопросы в разбор дня:
- Мечты (не цели — мечты, крупно)
- Спортивные увлечения и цели, рост/вес
- Направление в жизни, чем реально хочет заниматься
- Учреждение, нагрузка, расписание пар
- Хорошие привычки, которые уже есть
- Вредные привычки: что, когда срабатывает, какой триггер
- Слабости: где регулярно проигрывает
- **Страхи** — самый сложный блок, идёт последним, после того как сложилось доверие
- Люди: кто важен, с кем регулярный контакт

Каждый ответ уходит в `traits` / `goals` / `profile.extra`. Арвикс переспрашивает и уточняет, если ответ размыт: «"прокрастинация" — это не ответ. В какой момент конкретно ты открываешь телефон вместо задачи?»

**Стадия 3 — Постоянная.** Профиль никогда не «готов». Раз в месяц в ретро Арвикс проверяет: цели ещё актуальны? страх ещё действует? привычка ещё жива?

## 3. Сценарии бота

### 3.1. Утренний брифинг (пример)

```
☀️ 07:15 · Четверг · Учебный день

Сон 5ч40м. Второй день подряд. Режим ЖЁЛТЫЙ — план урезан на 30%.

Вчера: 5 из 8, глубокой работы 2ч10м. Вечер слил на короткие видео —
третий раз за неделю.

Сегодня три вещи:
1. 09:00 Алгоритмы: графы (90 мин, ДОЛГ 3 дня)
2. 14:00 Практика React (60 мин)
3. 19:00 Зал — квота спорта 1/3, среда уже прошла

Первый блок через 1ч45м. До него: завтрак, 20 минут на воздухе.
Ляжешь сегодня в 23:30. Не обсуждается.
```

### 3.2. Напоминание и контроль (без ИИ)

```
T-5 мин:  ⏱ Через 5 минут: Алгоритмы: графы · 90 мин · ДОЛГ
          [Начать сейчас] [Отложить 15 мин] [Не смогу]

T+0:      ▶️ Блок пошёл. 90 минут. Телефон убрал.

T+90:     Выполнил?
          [✅ Да] [⚠️ Частично] [❌ Нет]
```

- `✅` при `proof=confirm` → мгновенно закрывается, XP начислен, WS-пуш в TWA
- `✅` при `proof=report` → «В одном предложении: что именно сделал?»
- `✅` при `proof=photo` → «Фото» → Vision → вердикт
- `⚠️` → «Сколько процентов? Что помешало?» → частичный XP
- `❌` → L1 включается: разбор причины, решение о долге и штрафе

### 3.3. Изменение плана из чата

```
ЮЗЕР: Арвикс, я в 15:00 хочу погулять с подругой

[L1 вызывает propose_schedule_change → L0 возвращает факты:
 выполнено 3/9, глубокая 0:40/3:00, квота социум 0/2, конфликт с блоком «Алгоритмы»,
 долг 1 задача 3 дня, режим НОРМА, сон 7:50]

АРВИКС: Нет. 3 из 9 и 40 минут глубокой работы при норме три часа.
Сон нормальный — это не усталость, это выбор.

В 15:00 «Алгоритмы: графы», 90 минут, и это долг третий день.
Закроешь его — пиши, отпущу с 17:00.

Квота «социум» на неделе 0 из 2, так что гулять тебе надо.
Но не вместо долга.

Как её зовут?
```

При одобрении → `apply_schedule_change` → сдвиг блоков → WS-пуш → TWA перерисовалась без перезагрузки.

### 3.4. Вечерний разбор

```
🌙 22:30 · Разбор

Сделано: 6 из 8. Глубокая работа 2ч40м из 3ч. Зал был. Долг закрыт.
Квоты: спорт 2/3 · социум 1/2 · новое 0/1

День нормальный. Не отличный — два хвоста и поздний старт, — но нормальный.

Два вопроса:
1. Ты начал первый блок в 09:40 вместо 09:00. Это третий четверг подряд.
   Что происходит по четвергам утром?
2. Ты закрыл долг по алгоритмам. Было тяжело или ты просто тянул?

Завтра пятница — смена. План: 2 задачи, 1ч глубокой работы, отбой 23:30.
Подтверждаешь?
```

Вопросы генерирует Analyst под конкретный день — не шаблон.

```

АРВИКС: Не сейчас. Сначала сам.

Смотри: call stack, task queue, microtask queue. Три вещи.

раньше setTimeout(..., 0), если оба «асинхронные»?

Источники:
```

## 4. TWA — экраны

### 4.1. Главный (Dashboard)
- Шапка: уровень, XP-полоса, HP, стрик, **индикатор режима цветом**
- Круговая диаграмма дня: сон / работа / отдых против целевого 8/8/8, с подписью «дистанция до цели»
- Сегодня: список задач, свайп для закрытия, длинный тап — детали
- **Красный блок долга**, если есть
- Полоски квот недели
- Кнопка «Фокус» — старт сессии

### 4.2. Задачи / Расписание
**Главный экран по объёму работы.** Требование из ТЗ: настройка по неделям и по часам с минутами.

- Недельная сетка 7×24, скролл по часам, drag-n-drop блоков
- Тап по слоту → создание задачи: название, сфера, важность, сложность, длительность, deep_work, повтор
- Переключатель Неделя / День / Список
- Шаблоны дней: применить шаблон «Учебный» к пн-чт одним тапом
- Повторы: ежедневно / по дням недели / раз в N дней
- **Всё синхронно с ботом по WebSocket** — изменил в чате, экран перерисовался мгновенно

### 4.3. Цели и роадмапы
- Дерево: Мечта → Главная цель → Годовая → Квартальная → Веха
- Прогресс по метрике
- Роадмапы обучения: граф узлов, чекпоинты, источники, оценка часов, процент прохождения

### 4.4. Второй мозг (Obsidian)
- Дерево папок и файлов
- Просмотр и правка Markdown
- Поиск (гибридный: слова + смысл)
- Кнопка «Спросить Арвикса об этом файле»
- Inbox для быстрых заметок

### 4.5. Аналитика
- Графики за 7/30/90 дней: выполнение, сон, глубокая работа, HP, SP
- Корреляции: сон ↔ выполнение, тип дня ↔ результат
- **Autonomy Score** — отдельным крупным блоком с трендом
- Лента инсайтов от Analyst

### 4.6. Финансы
- Ввод в два тапа
- Недельный бюджет по категориям
- Прогресс целей накопления
- Импульсивные траты отдельным списком

### 4.7. Профиль и настройки
- Все поля профиля, цели, мечты, страхи, слабости, привычки — с возможностью правки
- Целевые: сон, бюджет недели, квоты
- **Включатель режима ментора** (выключается safety-контуром, включается только вручную здесь)
- Токены IoT: генерация, отзыв, список устройств, статус онлайн
- Настройки биометрии: источник (ручной / мост / экспорт)
- Экспорт и бэкап

## 5. Realtime-синхронизация

Требование «без обновления страницы» — жёсткое. Реализация:

```
Изменение в БД → событие в Redis pub/sub → WebSocket-хаб → все открытые клиенты
```

- TWA держит WS-соединение, переподключение с backoff
- Сообщения: `{type: "task_updated", payload: {...}}`, `{type: "state_changed", ...}`
- TanStack Query: WS-сообщение инвалидирует нужный кэш → точечный ререндер, без полного обновления
- Оптимистичные обновления в TWA: изменение рисуется сразу, откатывается при ошибке сервера
- **Единый источник правды — Postgres.** Чат, TWA и память Арвикса не «синхронизируются» между собой, они читают одно и то же

### Офлайн (PWA)
- Service Worker кэширует расписание на неделю вперёд и последние 30 дней статистики
- Офлайн-действия (закрытие задач) копятся в IndexedDB и отправляются при возврате сети
- Это часть анти-зависимости: сервер лёг — план у тебя на руках
