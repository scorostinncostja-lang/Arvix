# Workflow: Реализация шага из плана (/implement-step)

Когда пользователь просит реализовать конкретный шаг из `docs/09-PHASE-0-1-PLAN.md`:
1. Прочитай описание этого шага в `docs/09-PHASE-0-1-PLAN.md` и профильный документ в `docs/`.
2. Проверь существующие файлы, которые затрагивает этот шаг.
3. Выведи короткий план файлов (какие создашь, какие изменишь).
4. Напиши чистый, типизированный код без заглушек `TODO` в критической логике.
5. Напиши тест в `tests/` для проверки критерия готовности шага.
6. Запусти тесты и `ruff check`, исправь ошибки, если они есть.
7. Выдай краткое резюме: что сделано и как проверить.
