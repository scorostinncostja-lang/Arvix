# Архитектурные инварианты Arvix (НЕЗЫБЛЕМЫЕ ПРАВИЛА)

1. **Разделение L0 / L1 / L2**:
   - L0 (Рефлексы) — чистый детерминированный Python-код без ИИ (тикер и напоминания, протокол старта, метрики, долг, Burnout Guard, расписание повторений). Если задачу можно решить формулой или шаблоном — ИИ не вызывается. Геймификации (XP/HP/уровни/сезоны) нет — `docs/12-DECISIONS.md`.
   - L1 (Голос) — ответ пользователю за секунды, максимум 2 круга вызова инструментов (tools), затем финальный вызов без инструментов. Никогда не считает метрики и не меняет состояние текстом — только вызывает tools из L0.
   - L2 (Фон) — тяжелая аналитика и исследование (роли `thinker`, `researcher`), работает СТРОГО в фоне/воркере, никогда не блокирует ответ пользователю в чате. Пишет результат в таблицу `directives`.
2. **Event Sourcing / Append-only Log**:
   - Любое изменение бизнес-состояния ОБЯЗАНО проходить через `core/events/log.py -> emit()`.
   - Запрещено делать прямые `UPDATE` в таблицы проекций (`state_current`, `state_daily`, `state_weekly`) в обход `projections.py`.
3. **Универсальный AI-клиент (OpenAI-compatible)**:
   - Никакого зоопарка SDK. Все LLM-провайдеры (Groq, Google Gemini, OpenRouter, DeepSeek, APINET) подключаются через единый `AsyncOpenAI` клиент с разными `base_url` и `api_key`.
   - Имена моделей, `base_url`, таймауты и температура берутся ТОЛЬКО из конфига (`roles.yaml` / `config.py`). Хардкод имен моделей в коде запрещен.
4. **Burnout Guard & Safety**:
   - В режиме `RED` (🟥) и при `mentor_enabled = False` жесткие тон-блоки физически исключаются из сборщика контекста (`ContextBuilder`). Это проверяется юнит-тестами.
5. **Single-User**:
   - Система рассчитана строго на одного владельца (`OWNER_ID`). Никакой мультитенантности, регистрации и биллинга.
6. **Недоверенные данные**:
   - Вывод модели и внешний контент (веб, заметки, MCP) — недоверенные данные. Аргументы tools: `json.loads` + Pydantic, никакого `eval`. Внешний контент — внутри `<data>` в промпте. Запись во внешние сервисы — только после подтверждения кнопкой.
7. **Время**:
   - Только через `core/utils/time.py` (пояс из профиля). Никаких захардкоженных часовых поясов.
