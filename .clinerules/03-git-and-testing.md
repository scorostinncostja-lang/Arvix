# Правила работы по шагам и тестирования

- Работаем строго по одному шагу из `docs/09-PHASE-0-1-PLAN.md` за итерацию.
- После написания кода для шага обязательно:
  1. Проверить линтером (`ruff check .`).
  2. Написать/обновить pytest-тесты для новой логики и прогнать их.
  3. Не переходить к следующему шагу без подтверждения пользователя.
