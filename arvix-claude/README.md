# Arvix Lite — Арвикс внутри Claude Code и Telegram

Лёгкая версия Арвикса по спецификации из `../docs/`: без Docker, Postgres, Redis и TWA.
Одно ядро на чистом Python (без зависимостей) и три интерфейса:

| Интерфейс | Что даёт | Ограничение |
|---|---|---|
| **Claude Code** (CLI и вкладка Code в Desktop) | плагин: стиль «Arvix», 7 скиллов, MCP-инструменты, хук состояния | — |
| **Telegram** | бот пишет сам: брифинг, напоминания T−5/T+0/T+конец, разбор, ретро | работает, пока ноутбук не спит |
| **Чат Claude Desktop** | те же MCP-инструменты (`arvix desktop-mcp`) | — |
| **claude.ai** (браузер, телефон) | голос и методика: инструкции проекта + скилл-zip | без журнала, XP/HP и Obsidian |

## Как устроено

```
              Telegram ⇄ (long polling, без сервера)
                         │
 Claude Code ── MCP ──┐  ▼
 Claude Desktop ─ MCP ┤ arvix-telegram (systemd) ── claude -p (голова L1/L2, подписка)
 arvix CLI ───────────┤  │
                      ▼  ▼
            ядро arvix/ (L0: формулы, режимы, штрафы — без ИИ)
                      │
            ~/.local/share/arvix/arvix.db   ← журнал событий (append-only)
            Obsidian/Arvix/                 ← профиль, дни, инсайты, Inbox
```

Правила проекта соблюдены кодом, а не обещаниями:
1. XP, HP, долг, режим, напоминания — детерминированный Python (`rules.py`, `daily.py`, `telegram/scheduler.py`).
2. Совет (L2: разбор и ретро) работает в фоне или по запросу и пишет директивы; ответ в чат — один вызов L1.
3. Любое изменение — событие в `events`; UPDATE/DELETE запрещены триггерами SQLite, состояние — свёртка журнала.
4. Имена моделей — только в `arvix/defaults.toml` и `~/.config/arvix/config.toml` (`[roles.*]`).
5. В 🟥 и при выключенном менторе жёсткие тон-блоки и примеры физически не попадают в промпт — `tests/test_prompt_safety.py`.
6. Один пользователь: бот отвечает только `owner_id`, остальных молча игнорирует.

## Установка

```bash
bash arvix-claude/deploy/install.sh
arvix setup
systemctl --user enable --now arvix-telegram
```

`install.sh` копирует плагин в `~/.local/share/arvix/app` (путь без пробелов — его не сломает
перенос репозитория), ставит CLI `~/.local/bin/arvix`, подключает плагин к Claude Code
(маркетплейс `arvix`, scope user) и кладёт systemd-юнит. Повторный запуск — обновление.

`arvix setup` спросит путь к хранилищу Obsidian (подставит открытое), часовой пояс и,
по желанию, токен бота: создай бота у [@BotFather](https://t.me/BotFather) (`/newbot`),
вставь токен (ввод скрыт), напиши боту `/start` — так он узнает твой id и будет слушать
только тебя. Токен лежит в `~/.config/arvix/config.toml` с правами 600.

Проверка: `arvix doctor`. Логи бота: `journalctl --user -u arvix-telegram -f`.

## Первый запуск

```bash
cd ~/Arvix && claude
```
При первом запуске Claude Code спросит, доверяешь ли ты папке, — ответь «да». До этого он
игнорирует разрешения из `~/Arvix/.claude/settings.json` и будет спрашивать про каждый
инструмент. В Desktop: вкладка Code → новая сессия в папке `~/Arvix`.

Папка `~/Arvix` — «дом Арвикса»: там включён стиль `arvix:Arvix`, разрешены инструменты
`arvix` и чтение хранилища. Внутри скажи `/arvix:onboarding` — начнётся знакомство:
37 вопросов в 8 блоках, страхи последними, с паузой и продолжением. Перед вопросами Арвикс
прочитает твои заметки о целях и распорядке, чтобы не спрашивать то, что уже написано.
Из ответов про неделю он соберёт шаблоны дней — без них задач и напоминаний нет.

То же знакомство есть в Telegram (`/start`) и в терминале без ИИ (`arvix interview`).

## Скиллы Claude Code

| Скилл | Когда |
|---|---|
| `/arvix:onboarding` | знакомство, профиль, шаблоны дней |
| `/arvix:brief` | утро: брифинг и план дня |
| `/arvix:debrief` | вечер: разбор — факты, оценка, 2 вопроса, вывод, план завтра |
| `/arvix:retro` | неделя/месяц: паттерны с доказательствами → директивы |
| `/arvix:learn` | сократовский режим, роадмапы, чекпоинт «объясни» |
| `/arvix:notes` | поиск и выжимки по Obsidian, Inbox, экспорт |
| `arvix` | всё остальное: отчёты, сон, траты, «хочу погулять в 15:00» |

Вне `~/Arvix` скиллы и инструменты тоже доступны, но хук состояния молчит — обычные
кодинг-сессии не платят токенами за Арвикса.

## Telegram

Команды: `/day /week /status /done /add /sleep /spend /note /find /focus /reason /debrief
/answer /onboard /silent /sos /mentor /export /help`. Остальное — обычным текстом.

| Время | Что приходит | Кто решает |
|---|---|---|
| подъём + 15 мин | брифинг, вопрос про сон | код |
| T−5 / T+0 / T+конец | напоминание с кнопками, «Сделано?» | код |
| 15:00 | чек-ин, если выполнено < 40% | код |
| за 30 мин до отбоя | отбой | код |
| 22:30 | разбор: факты + оценка и 2 вопроса | код + модель (L2) |
| вс 20:00 | ретро недели, директивы | модель (L2) |

Протокол игнора (02-MECHANICS §7) соблюдается: день 2 — только утро и вечер, день 3 —
одно сообщение и заморозка штрафов, дни 4–7 — «Я здесь.», возврат — без разбора прошлого.
Штраф за неотчёт — только если бот реально спрашивал: выключенный ноутбук не наказывает.

Голова — `claude -p` по твоей подписке, без API-ключа: свой системный промпт, без MCP и
скиллов (~1.5k служебных токенов вместо ~43k). Лимит подписки кончился — бот отвечает
шаблоном, учёт и напоминания работают дальше.

## Claude Desktop и claude.ai

- Чат Claude Desktop: `arvix desktop-mcp` (или `install.sh --desktop`) и перезапуск приложения.
- claude.ai: создай проект «Арвикс», вставь `deploy/claude-ai/PROJECT_INSTRUCTIONS.md`
  в инструкции; скилл `deploy/claude-ai/arvix-skill.zip` загрузи в Settings → Capabilities → Skills.
  Там Арвикс без памяти: цифры состояния он не знает и не выдумывает.

## Данные

| Что | Где |
|---|---|
| журнал событий | `~/.local/share/arvix/arvix.db` (SQLite, WAL) |
| конфиг, токен бота | `~/.config/arvix/config.toml` |
| профиль, дни, инсайты | `<хранилище>/Arvix/` после `arvix export` или `/export` |
| копия плагина | `~/.local/share/arvix/app` |

`arvix rebuild` проверяет инварианты журнала на живой базе.

## Разработка

```bash
cd arvix-claude
python3 -m unittest discover -s tests -t .   # 67 тестов, без сети и без ИИ
python3 scripts/build_assets.py              # пересобрать стиль и файлы для claude.ai
claude --plugin-dir . plugin details arvix   # инвентарь плагина
```
Конституция, тон-блоки и примеры голоса — `arvix/constitution/`. Стиль и инструкции для
claude.ai генерируются из неё, тест проверяет, что они не устарели.

## Чего здесь нет по сравнению со спекой

TWA и realtime-синк, ESP32, Huawei-мост, проверка фото (EXIF, pHash, vision), векторный поиск
(вместо него поиск по основам слов), автовставка квот в четверг, переход рангов между сезонами
(ранг считается по среднему SP), рост бюджета недели по месяцам. Всё это ложится на тот же
журнал событий, если понадобится.
