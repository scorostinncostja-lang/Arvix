# Планирование

План — не список желаний, а то, что реально помещается в неделю. Пустой честный план лучше
фальшивого: провалы бьют по HP и уводят в долг.

## 1. Факты (до любых предложений)
1. `context` — режим, долг, квоты, директивы, главная цель и её следующий этап.
2. `day` на каждый планируемый день — что уже стоит по шаблону.
3. `profile` action=goals — дерево целей: какой этап сейчас двигаем.
4. Спроси одним сообщением, только если этого нет в контексте: что особенного на неделе
   (экзамены, смены, поездки, встречи), сколько часов реально свободно по дням.

## 2. Бюджет
- Бюджет недели — строка НАГРУЗКА контекста. Его решает автонагрузка (код, раз в неделю, по выполнению каждого
  канала, сну, HP и дням 🟨/🟥): человек часы не задаёт, ты тоже не придумываешь. Не планируй больше бюджета.
  Обязательное в шаблонах — `fixed: true`, остальное код масштабирует сам. Предупреждения ⚠️ о перегрузе недели/дня — сигнал убрать, а не «как-нибудь».
- Режим ЖЁЛТЫЙ — минус 30% нагрузки, глубокая работа только утром. КРАСНЫЙ — не планируй,
  только сон, еда, движение и одна маленькая вещь.
- Долг — первым, в ближайший свободный слот, с пометкой.
- Квоты (спорт, социум, новое, отдых без экрана) — вписать, если недобраны.

## 3. Расстановка
Порядок важности:
1. долг;
2. следующий этап главной цели — блоками глубокой работы в часы пика энергии (профиль, вопрос 15);
3. учёба или работа с дедлайнами;
4. квоты;
5. остальное.

Правила:
- не больше 3 задач важности 4–5 в день;
- блок глубокой работы — 60–120 минут, между блоками — перерыв;
- после смены или учёбы до вечера — не больше одного блока;
- у каждой задачи есть время начала: без него не будет напоминания.

Покажи план таблицей по дням (время · задача · длительность · важность) и дождись «да»
или правок. Только после подтверждения:
- разовые задачи → `task` action=add (date, start, duration_min, sphere, importance,
  difficulty, deep_work; tags: novelty / offscreen для квот);
- повторяющийся уклад → `profile` action=template для группы дней. Шаблон создаёт задачи
  каждое утро; разовое дело в шаблон не клади.

## 4. Перестройка по ходу недели
«Заболел», «перенесли экзамен», «сорвался вторник»:
- `check_request` → цифры;
- сдвинуть (`task` action=defer) или отменить с причиной (`task` action=cancel);
- провал того, что уже было, — `task` action=fail с причиной, а не тихая отмена.

Не перестраивай всё из-за одного плохого дня.

## 5. Итог
Три строки: главное на неделе, сколько часов глубокой работы заложено против бюджета,
какой этап цели закрываем к воскресенью. Ретро в воскресенье (`retro`) сверит план с фактом.
