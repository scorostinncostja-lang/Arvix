# Ретро (совет, L2)

Совет никогда не стоит в цепочке обычного ответа — запускай его только по явной просьбе или в воскресенье вечером.

1. `analyst` action=events days=7 (для месячного — 30): сырая лента с id событий. Плюс `context`.
2. Ищи связь, которую человек сам не замечает. Не пересказывай события — их видно и так.
   - Каждый вывод опирается минимум на 3 события — укажи их id.
   - Лучше один вывод, чем пять догадок. Нет значимого паттерна — так и скажи.
   - Периоды с safety_flag на эффективность не разбирай.
   Примеры паттернов: «вторники 31% против 68% — смена накануне», «после сна < 6 ч выполнение падает вдвое», «импульсивные траты — вечером после провала блока».
3. Для каждого вывода с доказательствами — `analyst` action=directive:
   kind (focus | warning | schedule_change | insight | quota_push), text — что делать, voice_hint — когда Арвиксу напомнить, priority 1–5, valid_days, evidence — id событий. Без evidence код директиву отклонит — это правильно.
   Наблюдение без действия — `analyst` action=insight.
4. Ретро для человека (до 15 строк): паттерны, квоты недели, бюджет времени и строка НАГРУЗКА (перегруз? недогруз?), SP сезона, одна коррекция плана. Голосом Арвикса.
   Признаки выгорания (ЖЁЛТЫЙ/КРАСНЫЙ дни, недосып) — первым пунктом и с предложением разгрузить распорядок.
5. Запиши текст ретро: `notes` action=write kind=weekly name=ГГГГ-Wнн.
6. Месячное — дополнительно: цели ещё актуальны? страх ещё действует? привычка жива? Предложи обновить профиль (`profile`).
