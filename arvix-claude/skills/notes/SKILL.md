# Obsidian

Правило 07-SECOND-BRAIN §1: читать можно всё хранилище, писать — только в папку `Arvix/`. Заметки человека Арвикс не редактирует никогда.

## Найти
1. `notes` action=search query=… (можно несколько формулировок: синонимы, английский термин).
2. Ответ — по форме 07 §2: сколько файлов, по каждому путь, раздел, дата и одна строка о чём там. Основное — первым. В конце один вопрос: открыть или сделать выжимку?
3. Выжимка — `notes` action=read по найденным файлам, структура со ссылками на файлы и заголовки (`[[Имя заметки#Заголовок]]`), без пересказа того, чего в заметках нет.

## Записать
- быстрая мысль → `notes` action=inbox (попадёт в `Arvix/Inbox.md` с датой);
- выжимка, роадмап, ретро → `notes` action=write path=`Arvix/<Папка>/<Имя>.md`;
- полный экспорт журнала, профиля и дней → `export`.

## Заметка по теме — только каркас
«Сделай заметку про производные» — Арвикс **не пишет конспект за человека**: готовый текст
от ИИ даёт ощущение знания без знания (00-VISION П2). Он создаёт каркас, который человек
заполняет сам:

1. `notes` action=search — что по теме уже есть; есть — дополняем, а не дублируем.
2. `notes` action=write path=`Arvix/Notes/<Тема>.md`:
```
---
type: arvix-skeleton
topic: <тема>
created: <дата>
---
# <Тема>
Зачем мне это: <связь с целью или этапом из контекста>

## Вопросы, на которые я должен ответить сам
1. <определение своими словами>
2. <как это работает / почему так>
3. <пример из жизни или задачи>
4. <типичная ошибка и как её избежать>
5. <как это связано с [[уже известная тема]]>

## Первоисточники
- <официальная документация / учебник, глава> — <минуты>
- <второй источник> — <минуты>

## Мои ответы
(пусто — заполняю сам)

## Чекпоинт
<как проверить: объяснить Арвиксу за 3–4 предложения / решить N задач / сделать мини-проект>
```
3. Предложи блок в плане на заполнение (`task` action=add, deep_work) и проверку через `learn`.
   Человек сам хочет перенести заметку в свою папку — пусть переносит; Арвикс пишет только в `Arvix/`.

Конспект целиком — только по явному «/answer» или «напиши за меня», и с пометкой в начале
файла: «Сгенерировано Арвиксом, не проверено мной».

## Ежедневная заметка человека
`notes` action=daily date=… читает заметку из папки ежедневных отчётов (настройки Obsidian) и поля frontmatter: подъём, сон, фокус, тренировка, срывы. Используй в брифинге и разборе вместо переспрашивания. Записать сон из заметки в журнал — `log` kind=sleep (с согласия человека).

В Claude Code можно читать файлы хранилища и встроенными инструментами Read/Grep — но писать всё равно только в `Arvix/`.
