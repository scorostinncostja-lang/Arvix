## 1. Что это и как устроено

Арвикс — внешний контур дисциплины. Он знает план, сам напоминает, спрашивает результат,
считает очки и штрафы, вечером проводит разбор и постепенно собирает о тебе профиль.
Он не делает за тебя задачи и не развлекает.

Ядро одно, интерфейсов три:

```
 Telegram (телефон) ⇄ бот на ноутбуке (systemd) ─┐
 Claude Code в ~/Arvix ── MCP-инструменты ───────┤
 терминал: arvix … ──────────────────────────────┤
                                                 ▼
                         ядро arvix  (правила без ИИ)
                                                 │
                ~/.local/share/arvix/arvix.db   журнал событий
                Obsidian Vault/Arvix/           профиль, дни, инсайты
```

Три слоя из спецификации:

| Слой | Что делает | Кто |
|---|---|---|
| **L0 — рефлексы** | напоминания, XP, HP, долг, режим, закрытие дня, квоты | обычный Python, модель не участвует |
| **L1 — голос** | ответы в чате: понять твоё сообщение, ответить, решить, какие действия записать | один вызов Claude на сообщение |
| **L2 — совет** | вечерний разбор и недельное ретро: найти паттерн, выдать директивы | Claude, только в фоне или по запросу |

Главный принцип: модель ничего не считает. Она пишет «закрыть задачу X, отчёт такой-то»,
а сколько это XP и HP, решает код. Поэтому числа нельзя «уговорить».

Любое изменение — это событие в журнале (`task_completed`, `sleep_recorded`,
`hp_changed`…). Журнал только дополняется: стереть или переписать прошлое нельзя даже
случайно. XP, HP и статистика каждый раз пересчитываются из журнала.

**Ноутбук — это сервер.** Бот сам опрашивает Telegram (long polling), поэтому ни домен,
ни публичный IP, ни вебхук не нужны. Ноутбук спит — бот молчит. Проснулся — догоняет:
закрывает пропущенные дни, но не засыпает тебя старыми напоминаниями. Чтобы бот жил
круглосуточно, его можно перенести на сервер (раздел 10).

## 2. Что уже стоит на ноутбуке

| Что | Где |
|---|---|
| Плагин Claude Code `arvix@arvix` | включён для всех проектов, файлы в `~/.local/share/arvix/app` |
| Команда `arvix` | `~/.local/bin/arvix` |
| Конфиг | `~/.config/arvix/config.toml` (хранилище и часовой пояс уже записаны) |
| Журнал | `~/.local/share/arvix/arvix.db` |
| Дом Арвикса | `~/Arvix` — папка для Claude Code в режиме Арвикса |
| Служба бота | `~/.config/systemd/user/arvix-telegram.service` (пока выключена) |

Проверить всё одной командой:

```bash
arvix doctor
```

Пока там будет одна строка `FAIL Telegram` — это нормально, бот ещё не подключён.

## 3. Подключить Telegram-бота

### 3.1. Создать бота
1. В Telegram открой [@BotFather](https://t.me/BotFather) и отправь `/newbot`.
2. Имя — любое, например «Арвикс».
3. Username — уникальный, заканчивается на `bot`, например `arvix_dastan_bot`.
4. BotFather пришлёт токен вида `123456789:AA...`. Это ключ от бота: никому не показывай
   и не вставляй в чаты, в том числе сюда.

По желанию у BotFather: `/setuserpic` — аватар, `/setdescription` — описание.

### 3.2. Привязать бота к себе
```bash
arvix setup
```
- Путь к хранилищу, часовой пояс и дом уже подставлены — жми Enter.
- «Настроить Telegram-бота сейчас?» — Enter (да).
- Вставь токен. Ввод скрыт, это нормально.
- Открой своего бота в Telegram и отправь `/start`.
- В терминале появится «Сообщение от … (id …). Это ты?» — ответь `y`.

После этого бот слушает только тебя: сообщения остальных игнорирует молча.
Токен и твой id записаны в `~/.config/arvix/config.toml` с правами 600.

### 3.3. Запустить бота
```bash
systemctl --user enable --now arvix-telegram
```
`enable` — запускать при входе в систему, `--now` — запустить сразу.

Проверить, что он жив:
```bash
systemctl --user status arvix-telegram
```
Смотреть логи в реальном времени:
```bash
journalctl --user -u arvix-telegram -f
```

Управление:

| Команда | Что делает |
|---|---|
| `systemctl --user restart arvix-telegram` | перезапуск (после правки конфига) |
| `systemctl --user stop arvix-telegram` | остановить |
| `systemctl --user disable --now arvix-telegram` | выключить совсем |

### 3.4. Чтобы бот работал без входа в систему
По умолчанию служба пользователя работает, пока ты залогинен. На ноутбуке этого хватает.
Если нужно, чтобы бот стартовал сразу после включения, ещё до входа:
```bash
loginctl enable-linger $USER
```

### 3.5. Сон ноутбука
При закрытой крышке бот спит вместе с ноутбуком. Что происходит после пробуждения:
- брифинг отправится, если с его времени прошло меньше 3 часов;
- напоминания о задачах, время которых давно прошло, не придут;
- вопрос «Сделано?» придёт в течение 3 часов после конца задачи;
- пропущенные дни закроются, но **штраф за неотчёт будет только за те дни, когда бот
  реально тебе писал**. Выключенный ноутбук тебя не наказывает.

## 4. Первый запуск в Claude Code

```bash
cd ~/Arvix && claude
```
1. Claude Code спросит, доверяешь ли ты папке — ответь «да». Без этого он не включит
   разрешения папки и будет спрашивать про каждый инструмент Арвикса.
2. Напиши `/arvix:onboarding` — начнётся знакомство.

В приложении Claude Desktop: вкладка **Code** → новая сессия → папка `~/Arvix`.

Что происходит в `~/Arvix` и чего нет в других папках:
- включён стиль ответа **Arvix**: Claude говорит как ментор, а не как ассистент;
- при старте сессии хук подкладывает текущее состояние: режим, задачи, HP, долг, цели;
- перед каждым сообщением — строка «сейчас / режим / день»;
- инструменты `arvix` и чтение хранилища разрешены без вопросов.

В других проектах скиллы и инструменты Арвикса тоже доступны (например, можно
отчитаться о задаче из кодинг-сессии), но хук молчит и токены не тратятся.

## 5. Знакомство: все 37 вопросов

### Как идёт интервью
- Где проходить: в Claude Code (`/arvix:onboarding`), в Telegram (`/start` или `/onboard`)
  или в терминале без ИИ (`arvix interview`). Прогресс общий: начал в Telegram —
  продолжишь в Claude Code с того же вопроса.
- В Claude Code Арвикс **сначала читает твои заметки**: `05_System/Цели 2026-2027.md`,
  `Распорядок дня.md`, `Как я учусь.md`. Что там уже написано, он не спрашивает заново,
  а уточняет: «В заметках подъём 7:00 — это ещё так?»
- Вопросы идут блоками по 3–4 штуки. Можно отвечать коротко.
- На размытый ответ будет один конкретный переспрос: «"прокрастинация" — не ответ.
  В какой момент ты открываешь телефон вместо задачи?»
- Пропустить вопрос: в Telegram — `/skip` или кнопка «Пропустить», в Claude Code — просто
  скажи «пропусти».
- Пауза в любой момент: `/pause` в Telegram или «давай потом». Продолжение — `/onboard`
  или снова `/arvix:onboarding`.
- После каждого блока Арвикс раскладывает ответы по полочкам — цели, привычки, триггеры,
  слабости, страхи, факты — и показывает, что записал.

### Блок 1. Ядро — без него система не запустится
1. Как к тебе обращаться?
2. В каком роде к тебе обращаться: «ты сделал» или «ты сделала»?
3. Город и часовой пояс? *(часовой пояс определяется по городу автоматически)*
4. Во сколько ложишься и встаёшь — реально, не в идеале? И во сколько хочешь?
   Формат: `01:30–09:00, цель 23:30–07:30`.
5. Расписание недели: какие дни и часы заняты учёбой, работой, сменами? По дням.
6. Одна главная цель на ближайший год. Измеримо: что именно и к какой дате.
7. Зачем тебе эта цель? Что изменится, когда она будет достигнута?

После этого блока Арвикс предложит **шаблоны дней** (раздел 9.4). Подтверди или поправь
их — без шаблонов бот не создаёт задач и не напоминает.

### Блок 2. Направление
8. Мечты — не цели, а крупно. Какой должна быть жизнь через 5–10 лет?
9. Чем ты реально хочешь заниматься? Не «надо», а «хочу».
10. Где учишься или работаешь, какая нагрузка, что даётся тяжелее всего?
11. Какие проекты ведёшь сейчас? Какой из них самый важный и почему?
12. Как через 3 месяца понять, что Арвикс работает? Одна-две измеримые вещи.

### Блок 3. Тело и энергия
13. Спорт: чем занимаешься, как часто, есть ли спортивная цель?
14. Рост и вес — если не против, для спортивных планов. Можно пропустить.
15. Когда в течение дня у тебя пик энергии, а когда провал?
16. Как с едой: регулярно ли ешь, что мешает?

### Блок 4. Привычки
17. Какие хорошие привычки уже держатся? Что делаешь стабильно?
18. Вредные привычки: что именно и сколько времени в день это съедает?
19. Что запускает срыв? Время, место, состояние, человек — конкретно.
20. Сколько часов в день телефон, игры и сериалы по учёту экрана? Честную цифру.
21. Что уже пробовал для дисциплины? Что работало и почему бросил?

### Блок 5. Как ты работаешь
22. Сколько минут можешь работать без отвлечений? Где лучше всего работается?
23. В какой момент конкретно ты открываешь телефон вместо задачи?
24. Что на тебя действует: жёсткость, цифры, соревнование, признание сделанного?
25. Где граница: какая жёсткость тебя мотивирует, а какая ломает?
26. Как ты учишься лучше всего: видео, книги, практика, объяснение другим?

### Блок 6. Деньги
27. Есть ли доход? Примерно сколько в месяц — одной цифрой, по желанию.
28. На что уходят деньги? Где бывают импульсивные траты?
29. Есть ли цель накопления? Сумма и срок.

### Блок 7. Люди
30. Кто для тебя важен? С кем регулярный контакт?
31. Общение тебя заряжает или выматывает? Сколько живых встреч в неделю — норма?
32. Кому можно написать, если станет по-настоящему плохо? *(это имя Арвикс назовёт,
    если сработает safety-контур)*

### Блок 8. Слабости и страхи — последним, когда уже есть доверие
33. Где ты регулярно проигрываешь сам себе?
34. О чём ты чаще всего врёшь себе — в отчётах, планах, оценках?
35. Чего ты боишься — в учёбе, работе, жизни?
36. Что ты делаешь после провала: бросаешь, наказываешь себя, делаешь вид, что ничего не было?
37. Каким должен быть идеальный ментор для тебя? И чего он не должен делать никогда?

### Совет
Не пытайся ответить на всё за один вечер. Полезный минимум — **блок «Ядро» и шаблоны
дней**: после них система уже работает. Остальное лучше растянуть на 1–2 недели, по блоку
за вечер: ответы будут честнее. Профиль никогда не бывает «готов» — раз в месяц в ретро
Арвикс проверит, актуальны ли цели и страхи.

После интервью: `/export` в Telegram или `arvix export` → профиль появится
в `Obsidian Vault/Arvix/Profile.md`.

## 6. Как проходит день

Пример будней (время настраивается, раздел 9.2):

| Время | Что приходит | Кто решает |
|---|---|---|
| **07:45** (подъём + 15 мин) | ☀️ брифинг: режим, итог вчера, задачи на сегодня, долг, квоты, время отбоя. Сон не записан — бот попросит ответить числом, например `7:20` | код |
| **за 5 мин до задачи** | ⏱ «Через 5 мин: Алгоритмы · 90 мин» + кнопки **Начать / Отложить 15 / Не смогу** | код |
| **начало задачи** | ▶️ «Блок пошёл. Телефон — убрать» | код |
| **конец задачи** | «Сделано: Алгоритмы?» + кнопки **✅ Да / ⚠️ Частично / ❌ Нет** | код |
| **15:00** | чек-ин, если выполнено меньше 40% | код |
| **за 30 мин до отбоя** | 🌙 «Через 30 минут отбой» | код |
| **22:30** | 🌙 разбор: факты дня, одна честная оценка, **два вопроса под этот день** | код + Claude |
| **воскресенье, 20:00** | 📊 ретро недели: паттерны и директивы | Claude |
| **04:00** | закрытие вчерашнего дня: штрафы, бонусы, регенерация, новые задачи по шаблону | код |

### Что значат кнопки после задачи
- **✅ Да**:
  - мелкая задача (важность 1–2) закроется сразу;
  - важность 3 и задачи глубокой работы — бот попросит одно предложение: что именно сделано;
  - важность 4–5 и спорт — фото-отчёт (фото с подписью) или одно предложение.
- **⚠️ Частично** — «60, не хватило времени»: XP начислится пропорционально.
- **❌ Нет** — HP снимется сразу. Важность 4–5 уйдёт в долг. Бот спросит причину,
  дальше короткий разбор.

### Свободный текст
Пиши боту как человеку, отвечает Claude:
- «Английский сделал, 30 карточек» — закроет задачу;
- «Спал 6 часов, лёг в час» — запишет сон и пересчитает режим;
- «Потратил 1200 на еду, импульсивно» — запишет трату;
- «Можно я в 15:00 погуляю?» — решит **по цифрам**: выполнение, долг, глубокая работа, квоты;
- «Как работает event loop?» — сократовский режим: подсказка, источники, 20 минут сам,
  без готового ответа (раздел 7.6).

В конце ответа бот дописывает, что код **реально** записал: «✅ Английский +11 XP».
Если код отказал — например, из-за долга, — честно пишет «⚠️ Не выполнено: …».

### Вечерний разбор — главное
Структура: факты → одна честная оценка → два вопроса → твой ответ одним сообщением →
один вывод «что меняем завтра» и план. Это единственное, что нельзя пропускать:
непройденный разбор стоит −8 HP.

## 7. Механики: XP, HP, режимы, долг, квоты

### 7.1. XP и уровни
```
XP = 10 × сложность × важность × подтверждение × время
сложность:     1→0.6  2→0.8  3→1.0  4→1.4  5→2.0
важность:      1→0.7  2→0.9  3→1.0  4→1.3  5→1.6
подтверждение: кнопка 1.0 · отчёт 1.1 · фото 1.3
время:         начал раньше плана 1.15 · вовремя ±15 мин 1.0 · опоздал 0.8
```
Бонусы: +25 за день на 100%, +15 за сон в норме, +40 за закрытую недельную квоту,
+50 за тихий день с выполнением от 70%.
Уровень N → N+1 стоит 100 + 20×(N−1) XP. **Уровень никогда не теряется.**

### 7.2. HP — здоровье, реагирует на тренд
Старт — 100. Регенерация +8 за день с выполнением от 70% и нормальным сном.

| Событие | Урон |
|---|---|
| провал задачи важности 1–2 / 3 / 4–5 | −2 / −5 / −12 |
| сон < 6 ч / < 5 ч | −6 / −12 |
| отбой позже цели на 2+ часа | −5 |
| пропущен разбор (если бот его задавал) | −8 |
| весь день молчал, хотя бот писал | −10 (один штраф вместо штрафа за каждую задачу) |
| 3 дня подряд < 40% | −20 один раз |
| задача в долге дольше 7 дней | −15 один раз |
| незакрытая недельная квота (в воскресенье) | −5 |

- **Щит** — 2 в месяц. Если день плохой по уважительной причине, напиши `/reason заболел`:
  при закрытии дня самый крупный урон отменится.
- **HP ≤ 30** — режим восстановления, штрафы действуют вполовину.

### 7.3. Burnout Guard — 4 режима
Режим считает код из сна, выполнения и HP. От режима зависит тон Арвикса.

| Режим | Когда | Как говорит Арвикс |
|---|---|---|
| 🟩 НОРМА | всё в порядке | требовательно, спокойно, конкретно |
| 🟦 ДАВЛЕНИЕ | выполнение < 50%, **хотя сон нормальный** | жёстко и коротко: «это выбор, а не усталость» |
| 🟨 ЖЁЛТЫЙ | сон < 6 ч два дня подряд или выполнение 20–40% | твёрдо, но без давления, план урезан |
| 🟥 КРАСНЫЙ | сон < 5 ч три дня, выполнение < 20% неделю, HP ≤ 20 или `/sos` | ментор выключен, штрафы заморожены, человеческий тон, без цифр |

В 🟥 жёсткие формулировки **физически не попадают** в промпт модели — это проверено тестом,
а не обещано на словах. Нет данных о сне — нет и «давления»: нельзя сказать «ты выспался»,
не зная этого.

### 7.4. Safety-контур
Если в сообщении признаки настоящей беды (а не «устал»), бот сразу:
- выключает режим ментора;
- переходит на человеческий тон без задач и цифр;
- советует написать живому человеку (тому, кого ты назвал в вопросе 32); при угрозе
  жизни — 112.

Обратно ментор включается **только тобой**: `/mentor on` или `arvix mentor on`.
Ни Claude, ни модель включить его не могут — такого инструмента нет.

### 7.5. Долг
Провалил задачу важности 4–5 — она уходит в долг и висит в брифинге. Пока в долге
2+ задачи, новые необязательные дела (сфера `social`) **блокируются**. Долг закрывается
выполнением или списывается с письменным обоснованием (в Claude Code: «спиши долг,
потому что…»).

### 7.6. Квоты недели
Недельные минимумы: спорт 3, социум 2, новое 1, отдых без экрана 3. Со среды
незакрытые квоты подсвечиваются в брифинге, в воскресенье проверяются. Живая встреча
засчитывается в квоту, если сказать о ней в чате («виделся с Тимуром») или записать
задачей в сфере `social`.

### 7.7. Протокол игнора — если ты пропал

| День молчания | Что делает бот |
|---|---|
| 1 | обычные напоминания, вечером: «Ты сегодня молчишь. Что происходит?» |
| 2 | только брифинг и разбор, тон жёстче |
| 3 | одно сообщение, **штрафы заморожены** |
| 4–7 | одно сообщение в день: «Я здесь.» |
| возврат | никакого разбора прошлого: один вопрос «что случилось» и один маленький шаг |

### 7.8. Тихий день
`/silent` — бот молчит до вечера, ты ведёшь день сам, разбор без штрафов. Можно сделать
тихий день автоматическим раз в неделю (раздел 9.2).

### 7.9. Сократовский режим
На учебный вопрос Арвикс не даёт готовый ответ: направление, наводящий вопрос,
2–3 источника (первоисточник — первым), «20 минут сам, потом объяснишь мне».
Если ответ уже есть в твоих заметках — отправит к заметке. Готовый ответ — после `/answer`
(это пишется в журнал). Роадмапы обучения лежат в `Obsidian/Arvix/Roadmaps/`.

## 9. Настройка под себя

Всё, кроме профиля, живёт в `~/.config/arvix/config.toml`. Правь его в любом редакторе,
после правки — `systemctl --user restart arvix-telegram`.

### 9.1. Полный пример конфига
```toml
timezone = "Europe/Moscow"
vault = "/home/dastan/Документы/Obsidian Vault"
home = "/home/dastan/Arvix"
arvix_folder = "Arvix"            # единственная папка хранилища, куда Арвикс пишет

[telegram]
token = "…"                       # пишет arvix setup
owner_id = 123456789

[schedule]
brief = "auto"                    # auto = подъём из профиля + 15 мин, или "07:30"
midday = "15:00"
debrief = "22:30"
retro_weekday = 6                 # 0 = пн … 6 = вс
retro = "20:00"
rollover = "04:00"                # до 04:00 вчерашний день ещё открыт для отчётов
bedtime_warning_min = 30
silent_weekday = -1               # например 6 = каждое воскресенье тихий день

[brain]
claude_bin = "/home/dastan/.npm-global/bin/claude"
timeout_sec = 180
vault_tools = true                # голова может читать хранилище (Read/Grep/Glob)

[roles.voice]                     # ответы в чате
model = "sonnet"
[roles.analyst]                   # разбор и ретро
model = "sonnet"

[mechanics]
sleep_target_min = 450            # 7.5 ч
deep_target_min = 120             # глубокая работа в день
week_budget_min = 1560            # 26 ч продуктивного времени в неделю
week_deep_budget_min = 480        # из них 8 ч глубокой работы
shields_per_month = 2

[mechanics.quotas]
sport = 3
social = 2
novelty = 1
offscreen = 3
```
Учти: `arvix setup` перезаписывает файл и удаляет из него комментарии. Значения сохраняются.

### 9.2. Расписание
- Будильник и брифинг: время подъёма берётся из профиля (вопрос 4), брифинг приходит
  через 15 минут. Фиксированное время: `brief = "07:30"`.
- Сова и ложишься в 2 ночи: сдвинь `rollover = "05:00"` — до этого времени можно
  отчитаться за вчера.
- Тихий день раз в неделю: `silent_weekday = 6` (воскресенье).

### 9.3. Модели и расход подписки
«Голова» — это `claude -p` по твоей подписке **Pro**, лимит общий с обычной работой
в Claude Code.
- Экономнее и быстрее: `[roles.voice] model = "haiku"`.
- Умнее разбор и ретро: `[roles.analyst] model = "opus"` (на Pro расходует лимит быстрее).
- Лимит кончился — бот отвечает шаблоном. Кнопки, напоминания, XP и HP работают дальше,
  потому что им модель не нужна.

Примерный расход: одно сообщение в чат — один вызов (~2–5 тысяч токенов), разбор — один-два,
ретро — один в неделю.

### 9.4. Шаблоны дней — главное, что делает план «твоим»
Из шаблона каждое утро создаются задачи. Тип дня: `study` (учебный), `work` (смена),
`deep` (глубокий), `recovery` (восстановление), `silent` (тихий).

Проще всего настроить словами в Claude Code (в `~/Arvix`):
> «Пн–чт у меня колледж до 14:00. Сделай учебные дни: 16:00 алгоритмы 90 минут глубокой
> работы, 19:00 английский 30 минут. Пт–вс смены до 20:00 — один блок 21:00 на 40 минут.»

Claude покажет шаблоны, ты подтвердишь — они сохранятся. Поменять — тоже словами:
«в среду вместо английского зал в 18:00».

Поля блока: время начала, длительность, название, сфера (`learning`, `work`, `sport`,
`social`, `health`, `finance`, `project`, `chore`), важность 1–5, сложность 1–5, глубокая
работа да/нет, теги (`novelty` — новое, `offscreen` — отдых без экрана, считаются в квоты).

Чем выше важность, тем строже подтверждение и больнее провал. Ставь 4–5 только тому,
что правда критично.

### 9.5. Характер Арвикса
Голос задан файлами в `arvix-claude/arvix/constitution/`:

| Файл | Что задаёт |
|---|---|
| `identity.md`, `mission.md` | кто он и зачем |
| `voice.md` | как говорит: коротко, с цифрами, без лести, максимум один вопрос |
| `autonomy_rule.md` | сократовский режим |
| `decision_rule.md` | решения по цифрам |
| `honesty.md`, `boundaries.md`, `safety_override.md` | честность, границы, безопасность |
| `tone_norm.md` / `tone_pressure.md` / `tone_yellow.md` / `tone_red.md` | тон в каждом режиме |
| `fewshot.json` | 8 примеров «ситуация → ответ Арвикса» |
| `channel_telegram.md` | правила для Telegram и формат ответа модели |

Если Арвикс звучит не так — **правь примеры в `fewshot.json`**, а не правила: характер
лучше передаётся примерами. Пример с `"harsh": true` в 🟥 не попадёт в промпт.

После правки:
```bash
cd ~/"Рабочий стол/Projects/Arvix/arvix-claude"
python3 scripts/build_assets.py
python3 -m unittest discover -s tests -t .
bash deploy/install.sh
```
Первая команда пересобирает стиль для Claude Code из конституции, вторая проверяет,
что в 🟥 жёсткий тон по-прежнему отсекается, третья копирует обновление и перезапускает бота.

### 9.6. Память о тебе
Скажи в Claude Code или в Telegram: «запомни: после смены я ничего не могу» — факт
сохранится и будет подставляться в контекст. Посмотреть всё, что Арвикс о тебе знает:
«покажи мой профиль» или `Obsidian/Arvix/Profile.md` после экспорта. Забыть: «забудь факт про …».

### 9.7. Твой ежедневный отчёт в Obsidian
Арвикс читает твою ежедневную заметку из `08_Daily Report/` (папку берёт из настроек
Obsidian) и поля frontmatter: `wake`, `sleep`, `focus_min`, `workout`, `relapses`…
Заполнил отчёт — в брифинге и разборе Claude использует эти данные, а не переспрашивает.
Твои заметки он **никогда не редактирует**: пишет только в `Arvix/`.

## 10. Перенос бота на сервер (VPS)

Зачем: бот пишет круглосуточно, даже когда ноутбук закрыт.

**Важно понять до переноса:** журнал событий должен жить в одном месте. Если бот на сервере,
то и база на сервере, а Claude Code на ноутбуке со своей локальной базой разойдётся с ней.
Поэтому при переносе Claude Code работает с Арвиксом **через SSH на сервер** — вкладка
Code в Claude Desktop умеет SSH-сессии, или просто `ssh vps` → `cd ~/Arvix && claude`.
Копировать SQLite между машинами туда-обратно нельзя: получишь две разные истории.

### 10.1. Сервер
Подойдёт самый дешёвый VPS (1 ядро, 1 ГБ RAM) с Ubuntu или Debian. Нужен Python 3.11+.

### 10.2. Хранилище Obsidian на сервере
Боту нужна копия хранилища. Варианты:
- **Git** (как в спеке 07): плагин Obsidian Git на ноутбуке коммитит каждые 10 минут
  в приватный репозиторий, на сервере cron делает `git pull`. Изменения Арвикса
  (`Arvix/`) сервер коммитит обратно.
- **Syncthing**: двусторонняя синхронизация папки без Git.

### 10.3. Установка
```bash
# на сервере
sudo apt install -y python3 git rsync
curl -fsSL https://claude.ai/install.sh | bash        # Claude Code
claude setup-token                                     # долгоживущий токен подписки
git clone https://github.com/scorostinncostja-lang/Arvix.git
bash Arvix/arvix-claude/deploy/install.sh
arvix setup                                            # путь к хранилищу на сервере, тот же токен бота
```
`claude setup-token` выдаёт токен для работы без браузера — сохрани его так, как
предложит команда (обычно это переменная `CLAUDE_CODE_OAUTH_TOKEN`). Чтобы служба его
видела, добавь в юнит строку:
```bash
systemctl --user edit arvix-telegram
```
```ini
[Service]
Environment=CLAUDE_CODE_OAUTH_TOKEN=…
```

### 10.4. Перенести историю и запустить
```bash
# на ноутбуке: остановить бота, чтобы не было двух ботов с одним токеном
systemctl --user disable --now arvix-telegram
scp ~/.local/share/arvix/arvix.db vps:~/.local/share/arvix/arvix.db
```
```bash
# на сервере
loginctl enable-linger $USER
systemctl --user enable --now arvix-telegram
```
Два запущенных бота с одним токеном мешают друг другу: Telegram отдаёт сообщения то одному,
то другому. Держи ровно один.

| Что | Где |
|---|---|
| журнал (вся история) | `~/.local/share/arvix/arvix.db` |
| конфиг и токен бота | `~/.config/arvix/config.toml` (права 600) |

cp ~/.local/share/arvix/arvix.db ~/arvix-backup-$(date +%F).db

**Что уходит наружу:**
- в Anthropic — текст сообщений и контекст дня при каждом вызове «головы»;

лежат отдельно специально.

## 13. Если что-то сломалось

| Симптом | Что делать |
|---|---|
| Бот не отвечает | `systemctl --user status arvix-telegram`, потом `journalctl --user -u arvix-telegram -n 50` |
| «Голова сейчас недоступна» | кончился лимит подписки или нет сети; `arvix brain-test` покажет, отвечает ли Claude |
| В Claude Code спрашивает разрешение на каждый инструмент | папке `~/Arvix` не дали доверие — запусти `claude` там интерактивно и ответь «да» |
| Нет стиля Arvix | сессия открыта не в `~/Arvix`; или `/output-style arvix:Arvix` |
| Нет задач и напоминаний | не настроены шаблоны дней (раздел 9.4) |
| Режим «застрял» в 🟥 | возможно, выключен ментор: `/status`, вернуть — `/mentor on`; SOS снимается `/sos off` |
| Сомнения в цифрах | `arvix rebuild` — проверка, что пересчёт журнала совпадает с текущим состоянием |
| Обновил код в репозитории | `bash arvix-claude/deploy/install.sh` — скопирует и перезапустит бота |
| Общая проверка | `arvix doctor` |

## 14. Ограничения

- Пока ноутбук спит, бот молчит — до переноса на сервер (раздел 10).
- Фото-отчёт принимается без проверки: трение и ритуал, а не верификация.
- Поиск по заметкам — по словам и их основам, без векторного поиска; на сотнях заметок
  этого хватает.
- Нет из спецификации: TWA (веб-приложение в Telegram), ESP32-таймер, данные с часов
  Huawei, автоматический рост бюджета недели, смена рангов между сезонами.
- Протокол Ноль (HP = 0) по текущим правилам недостижим: при HP ≤ 20 включается 🟥
  и штрафы замораживаются. Это противоречие в самой спецификации, решение за тобой.
