## 1. Что это и как устроено

Арвикс — внешний контур дисциплины. Он знает план, сам напоминает, спрашивает результат,
ведёт долг и режим нагрузки, вечером проводит разбор и постепенно собирает о тебе профиль.
Он не делает за тебя задачи и не развлекает.

Ядро одно, интерфейсов три:

```
 Telegram (телефон) ⇄ бот (сервер или ноутбук) ──┐
 Claude Code в ~/Arvix ── MCP-инструменты ───────┤
 терминал: arvix … ──────────────────────────────┤
                                                 ▼
                         ядро arvix  (правила без ИИ)
                                                 │
                ~/.local/share/arvix/arvix.db   журнал событий
                Obsidian Vault (твоя структура) профиль, цели, роадмапы, отчёты
```

Три слоя из спецификации:

| Слой | Что делает | Кто |
|---|---|---|
| **L0 — рефлексы** | напоминания, долг, режим, закрытие дня, квоты | обычный Python, модель не участвует |
| **L1 — голос** | ответы в чате: понять твоё сообщение, ответить, решить, какие действия записать | один вызов Claude на сообщение |
| **L2 — совет** | вечерний разбор и недельное ретро: найти паттерн, выдать директивы | Claude, только в фоне или по запросу |

Главный принцип: модель ничего не считает. Она пишет «закрыть задачу X, отчёт такой-то»,
а что из этого следует (долг, режим), решает код. Поэтому решения нельзя «уговорить».

Любое изменение — это событие в журнале (`task_completed`, `sleep_recorded`,
`hp_changed`…). Журнал только дополняется: стереть или переписать прошлое нельзя даже
случайно. Долг, режим и статистика каждый раз пересчитываются из журнала.

**Бот живёт там, где запущен.** Он сам опрашивает Telegram (long polling), поэтому ни домен,
ни публичный IP, ни вебхук не нужны. На сервере (раздел 10) он пишет круглосуточно. На ноутбуке:
ноутбук спит — бот молчит; проснулся — догоняет: закрывает пропущенные дни, но не засыпает
тебя старыми напоминаниями и не пишет в долг то, о чём не спрашивал.

## 2. Что стоит на ноутбуке

Ставится одной командой `bash arvix-claude/deploy/install.sh` (повторный запуск — обновление):

| Что | Где |
|---|---|
| Плагин Claude Code `arvix@arvix` | scope user — во всех проектах; читается из `~/.local/share/arvix/app` |
| Команда `arvix` | `~/.local/bin/arvix` |
| Конфиг | `~/.config/arvix/config.toml` — пишет `arvix setup` |
| Журнал | `~/.local/share/arvix/arvix.db` |
| Дом Арвикса | `~/Arvix` — стиль Arvix, разрешения, строка состояния |
| Службы | `arvix-telegram.service` (бот) и `arvix-backup.timer` (копия журнала с сервера) — выключены, пока не включишь |
| Чат Claude Desktop | MCP-сервер `arvix` в `~/.config/Claude/claude_desktop_config.json` (`arvix desktop-mcp`) |

Настройка без вопросов — хранилище, часовой пояс, дом; Telegram потом:

```bash
arvix setup --vault "$HOME/Документы/Obsidian Vault" --tz Europe/Moscow --home ~/Arvix --no-telegram --yes
```

`setup` сам находит в хранилище папку роадмапов, Inbox и шаблон ежедневного отчёта
и записывает их в `[vault_paths]` (в этом хранилище: `02_Areas/Роадмапы`,
`00_Inbox/Входящие.md`, `05_System/Templates/Daily Report.md`).

Проверить всё одной командой:

```bash
arvix doctor
```

Пока там будет строка `FAIL Telegram токен и владелец` — это нормально, бот ещё не подключён.

## 3. Подключить Telegram-бота

### 3.1. Создать бота
1. В Telegram открой [@BotFather](https://t.me/BotFather) и отправь `/newbot`.
2. Имя — любое, например «Арвикс».
3. Username — уникальный, заканчивается на `bot`, например `arvix_dastan_bot`.
4. BotFather пришлёт токен вида `123456789:AA...`. Это ключ от бота: никому не показывай
   и не вставляй в чаты, в том числе сюда.

По желанию у BotFather: `/setuserpic` — аватар, `/setdescription` — описание.

### 3.2. Привязать бота к себе
```bash
arvix setup --telegram --yes
```
- Хранилище, часовой пояс и дом остаются как есть (без `--yes` команда переспросит их — жми Enter).
- Вставь токен. Ввод скрыт, это нормально. Токен вводится только в терминале — в чаты
  и логи он не попадает.
- Открой своего бота в Telegram и отправь `/start`.
- В терминале появится «Сообщение от … (id …). Это ты?» — ответь `y`.

После этого бот слушает только тебя: сообщения остальных игнорирует молча.
Токен и твой id записаны в `~/.config/arvix/config.toml` с правами 600.

### 3.3. Запустить бота
```bash
systemctl --user enable --now arvix-telegram
```
`enable` — запускать при входе в систему, `--now` — запустить сразу.

Проверить, что он жив:
```bash
systemctl --user status arvix-telegram
```
Смотреть логи в реальном времени:
```bash
journalctl --user -u arvix-telegram -f
```

Управление:

| Команда | Что делает |
|---|---|
| `systemctl --user restart arvix-telegram` | перезапуск (после правки конфига) |
| `systemctl --user stop arvix-telegram` | остановить |
| `systemctl --user disable --now arvix-telegram` | выключить совсем |

### 3.4. Чтобы бот работал без входа в систему
По умолчанию служба пользователя работает, пока ты залогинен. На ноутбуке этого хватает.
Если нужно, чтобы бот стартовал сразу после включения, ещё до входа:
```bash
loginctl enable-linger $USER
```

### 3.5. Сон ноутбука
При закрытой крышке бот спит вместе с ноутбуком. Что происходит после пробуждения:
- брифинг отправится, если с его времени прошло меньше 3 часов;
- напоминания о задачах, время которых давно прошло, не придут;
- вопрос «Сделано?» придёт в течение 3 часов после конца задачи;
- пропущенные дни закроются, но **в долг уйдёт только то, о чём бот реально тебе писал**.
  Выключенный ноутбук тебя не наказывает.

## 4. Первый запуск в Claude Code

```bash
cd ~/Arvix && claude
```
1. Claude Code спросит, доверяешь ли ты папке — ответь «да». Без этого он не включит
   разрешения папки и будет спрашивать про каждый инструмент Арвикса.
2. Ничего вводить не нужно: пока профиль пуст, Арвикс представится и **сам начнёт
   знакомство** — сначала прочитает хранилище, потом блок «Ядро» по 3–4 вопроса.
   Продолжить в другой раз — `/arvix:onboarding`.

В приложении Claude Desktop: вкладка **Code** → новая сессия → папка `~/Arvix`.

Что происходит в `~/Arvix` и чего нет в других папках:
- включён стиль ответа **Arvix**: Claude говорит как ментор, а не как ассистент;
- при старте сессии хук подкладывает текущее состояние: режим, задачи, долг, цели;
- перед каждым сообщением — строка «сейчас / режим / день»;
- внизу окна — **строка состояния**: `🟩 НОРМА · сегодня 2/5 · → 16:00 Алгоритмы · ctx 7%`.
  Обновляется после каждого ответа и раз в минуту; в 🟥 и при выключенном менторе — без цифр;
- инструменты `arvix` и чтение хранилища разрешены без вопросов.

В других проектах скиллы и инструменты Арвикса тоже доступны (например, можно
отчитаться о задаче из кодинг-сессии), но хук молчит и токены не тратятся.

## 5. Знакомство: все 52 вопроса

### Как идёт интервью
- Где проходить: в Claude Code (`/arvix:onboarding`), в Telegram (`/start` или `/onboard`)
  или в терминале без ИИ (`arvix interview`). Прогресс общий: начал в Telegram —
  продолжишь в Claude Code с того же вопроса.
- В Claude Code Арвикс **сначала читает всё хранилище**: цели, распорядок, «как я учусь»,
  твои методы обучения из `03_Resources/Обучение`, карты предметов, расписание ОГЭ. Что там
  уже написано, он не спрашивает заново, а уточняет: «В заметках подъём 7:00 — это ещё так?»
- Порядок в Claude Code: хранилище → оставшиеся вопросы → распорядок дня → цели → роадмапы →
  шаблон ежедневного отчёта → нагрузка. Всё это делает один `/arvix:onboarding`.
- Вопросы идут блоками по 3–4 штуки. Можно отвечать коротко.
- На размытый ответ будет один конкретный переспрос: «"прокрастинация" — не ответ.
  В какой момент ты открываешь телефон вместо задачи?»
- Пропустить вопрос: в Telegram — `/skip` или кнопка «Пропустить», в Claude Code — просто
  скажи «пропусти».
- Пауза в любой момент: `/pause` в Telegram или «давай потом». Продолжение — `/onboard`
  или снова `/arvix:onboarding`.
- После каждого блока Арвикс раскладывает ответы по полочкам — цели, привычки, триггеры,
  слабости, страхи, факты — и показывает, что записал.

### Блок 1. Ядро
1. Как к тебе обращаться?
2. В каком роде к тебе обращаться: «ты сделал» или «ты сделала»?
3. Город и часовой пояс? Сейчас в настройках Europe/Moscow.
4. Во сколько ложишься и встаёшь — реально, не в идеале? И во сколько хочешь? Формат: 01:30–09:00, цель 23:30–07:30.
5. Расписание недели: какие дни и часы заняты учёбой, работой, сменами? По дням.
6. Одна главная цель на ближайший год. Измеримо: что именно и к какой дате.
7. Зачем тебе эта цель? Что изменится, когда она будет достигнута?

После этого блока Арвикс предложит **распорядок дня** (раздел 9.4).

### Блок 2. Учёба
8. Какие предметы для тебя главные — нужны для экзаменов и поступления? Какие даются легко, а какие тяжело?
9. Где ты сейчас по главным предметам: оценки, баллы пробников, что конкретно не получается?
10. Какие экзамены впереди (ОГЭ/ЕГЭ — какие предметы, олимпиады, сессия)? Даты и сколько баллов нужно.
11. Что после текущей ступени: старшая школа, колледж, вуз? Куда хочешь поступить — заведение, направление, страна?
12. Чем пользуешься для учёбы: Obsidian, Anki, YouTube, онлайн-школы, репетиторы, учебники, нейросети? Что реально помогает, а что для галочки?
13. Как проходит твоё учебное занятие от начала до конца? Как проверяешь, что понял, а не просто прочитал?
14. Где застреваешь чаще всего: не понимаю материал, не могу сесть, забываю через неделю, нет плана, не знаю, что учить?
15. Сколько часов в неделю ты реально готов учиться сверх школы? А сколько сможешь, не выгорая?

От этого блока зависят роадмапы и стартовый бюджет часов: ответ на последний вопрос — сколько часов в неделю ты потянешь.

### Блок 3. Направление
16. Мечты — не цели, а крупно. Какой должна быть жизнь через 5–10 лет?
17. Чем ты реально хочешь заниматься? Не «надо», а «хочу».
18. Где учишься или работаешь, какая нагрузка, что даётся тяжелее всего?
19. Какие проекты ведёшь сейчас? Какой из них самый важный и почему?
20. Как через 3 месяца понять, что Арвикс работает? Одна-две измеримые вещи.
21. Какие профессии и направления рассматриваешь? Что о них уже знаешь — чем там занимаются, какие требования, какой путь?

### Блок 4. Распорядок дня
22. Опиши обычный учебный день по часам: подъём, дорога, учёба, еда, свободное время, отбой.
23. А выходной? Во сколько встаёшь, что обычно делаешь, что меняется?
24. Что в неделе нельзя двигать: тренировки, работа, кружки, репетиторы, семья? Дни и часы.
25. Какие окна свободного времени реально есть по дням недели — куда можно ставить учёбу?
26. Как ты отдыхаешь так, чтобы реально восстановиться? Сколько отдыха в день тебе нужно?
27. По каким признакам понятно, что ты перегрузился или выгораешь? Что тогда помогает?

Сразу после блока бот пришлёт **распорядок недели** с кнопками «✅ Сохранить» и «✏️ Поправить». Без распорядка нет задач и напоминаний.

### Блок 5. Тело и энергия
28. Спорт: чем занимаешься, как часто, есть ли спортивная цель?
29. Рост и вес — если не против, для спортивных планов. Можно пропустить.
30. Когда в течение дня у тебя пик энергии, а когда провал?
31. Как с едой: регулярно ли ешь, что мешает?

### Блок 6. Привычки
32. Какие хорошие привычки уже держатся? Что делаешь стабильно?
33. Вредные привычки: что именно и сколько времени в день это съедает?
34. Что запускает срыв? Время, место, состояние, человек — конкретно.
35. Сколько часов в день телефон, игры и сериалы по учёту экрана? Честную цифру.
36. Что уже пробовал для дисциплины? Что работало и почему бросил?

### Блок 7. Как ты работаешь
37. Сколько минут можешь работать без отвлечений? Где лучше всего работается?
38. В какой момент конкретно ты открываешь телефон вместо задачи?
39. Что на тебя действует: жёсткость, цифры, соревнование, признание сделанного?
40. Где граница: какая жёсткость тебя мотивирует, а какая ломает?
41. Как ты учишься лучше всего: видео, книги, практика, объяснение другим?

### Блок 8. Деньги
42. Есть ли доход? Примерно сколько в месяц — одной цифрой, по желанию.
43. На что уходят деньги? Где бывают импульсивные траты?
44. Есть ли цель накопления? Сумма и срок.

### Блок 9. Люди
45. Кто для тебя важен? С кем регулярный контакт?
46. Общение тебя заряжает или выматывает? Сколько живых встреч в неделю — норма?
47. Кому можно написать, если станет по-настоящему плохо? Имя или роль — на случай safety-контура.

### Блок 10. Слабости и страхи
48. Где ты регулярно проигрываешь сам себе?
49. О чём ты чаще всего врёшь себе — в отчётах, планах, оценках?
50. Чего ты боишься — в учёбе, работе, жизни?
51. Что ты делаешь после провала: бросаешь, наказываешь себя, делаешь вид, что ничего не было?
52. Каким должен быть идеальный ментор для тебя? И чего он не должен делать никогда?

Самый личный блок — последним, когда уже есть доверие. Любой вопрос можно пропустить.

### Совет
Не пытайся ответить на всё за один вечер. Полезный минимум — **блок «Ядро» и шаблоны
дней**: после них система уже работает. Остальное лучше растянуть на 1–2 недели, по блоку
за вечер: ответы будут честнее. Профиль никогда не бывает «готов» — раз в месяц в ретро
Арвикс проверит, актуальны ли цели и страхи.

После интервью: `/export` в Telegram или `arvix export` → профиль появится
в `05_System/Профиль Арвикса.md`.

## 6. Как проходит день

Пример будней (время настраивается, раздел 9.2):

| Время | Что приходит | Кто решает |
|---|---|---|
| **07:45** (подъём + 15 мин) | ☀️ брифинг: режим, итог вчера, задачи на сегодня, долг, квоты, время отбоя. Сон не записан — бот попросит ответить: `7:20` или словами «лёг в час, встал в 8:30» | код |
| **за 5 мин до задачи** | ⏱ «Через 5 мин: Алгоритмы · 90 мин» + кнопки **Начать / Отложить 15 / Не смогу** | код |
| **начало задачи** | ▶️ «Блок пошёл. Телефон — убрать» | код |
| **конец задачи** | «Сделано: Алгоритмы?» + кнопки **✅ Да / ⚠️ Частично / ❌ Нет** | код |
| **15:00** | чек-ин, если выполнено меньше 40% | код |
| **за 30 мин до отбоя** | 🌙 «Через 30 минут отбой» | код |
| **22:30** | 🌙 разбор: факты дня, одна честная оценка, **два вопроса под этот день** | код + Claude |
| **воскресенье, 20:00** | 📊 ретро недели: паттерны и директивы | Claude |
| **04:00** | закрытие вчерашнего дня: неотмеченное важное — в долг, итог дня; новые задачи по шаблону | код |

### Что значат кнопки после задачи
- **✅ Да**:
  - мелкая задача (важность 1–2) закроется сразу;
  - важность 3 и задачи глубокой работы — бот попросит одно предложение: что именно сделано;
  - важность 4–5 и спорт — фото-отчёт (фото с подписью) или одно предложение.
- **⚠️ Частично** — «60, не хватило времени»: задача засчитается долей в выполнении дня.
- **❌ Нет** — задача не сделана. Важность 4–5 уйдёт в долг. Бот спросит причину,
  дальше короткий разбор.

### Свободный текст
Пиши боту как человеку или отправляй **голосовое** (раздел 9.10), отвечает Claude:
- «Английский сделал, 30 карточек» — закроет задачу;
- «Спал 6 часов, лёг в час» — запишет сон и пересчитает режим;
- «Потратил 1200 на еду, импульсивно» — запишет трату;
- «Можно я в 15:00 погуляю?» — назовёт **цену в цифрах** (выполнение, долг, глубокая работа, квоты)
  и вариант; решаешь ты, он запишет;
- «Как работает event loop?» — сократовский режим: подсказка, источники, 20 минут сам,
  без готового ответа (раздел 7.9).

В конце ответа бот дописывает, что код **реально** записал: «✅ Английский».
Если код отказал — например, из-за долга, — честно пишет «⚠️ Не выполнено: …».
Если записанное не сходится с данными — «⚠️ Проверь: …» (раздел 7.10).

### Вечерний разбор — главное
Структура: факты → одна честная оценка → два вопроса → твой ответ одним сообщением →
один вывод «что меняем завтра» и план. Это единственное, что нельзя пропускать:
без разбора день не превращается в вывод на завтра.

## 7. Механики: режимы, долг, квоты

### 7.1. Очков и уровней нет
С версии 0.6 у Арвикса **нет игры**: ни XP, ни уровней, ни бонусов, ни сезонов, ни серии дней.
Такие числа легко врут: очки давались за нажатие кнопки, а не за результат. Вместо них —
только то, что было на самом деле:
- **сегодня**: сколько задач из плана сделано (частичное — долей), сколько глубокой работы;
- **неделя**: часы сделанного против бюджета, глубокая работа, квоты;
- **сон**: сколько спал и средний сон против твоей нормы;
- **долг**: какие важные дела висят.

Всё это — по кнопке **📊 Итоги** (или «как неделя?», `arvix status`).

### 7.2. Здоровья (HP) нет
Урона, регенерации, щитов и Протокола Ноль тоже больше нет. Что от них осталось по смыслу:
- **Долг.** Важное (4–5), не сделанное, уходит в долг — и висит, пока не закроешь или не спишешь
  с обоснованием. Никаких очков он не отнимает.
- **Причина дня.** Плохой день по уважительной причине — напиши «заболел» (или `/reason заболел`):
  важное, не сделанное сегодня, в долг не уйдёт, причина попадёт в разбор.
- **Заморозка.** В 🟥, в тихий день, при выключенном менторе и с третьего дня молчания долга нет:
  бот о задачах не напоминал — значит, и спрашивать не за что.

### 7.3. Burnout Guard — 4 режима
Режим считает код из сна и выполнения (и твоей просьбы «сегодня без сил»). От режима зависит тон Арвикса.

| Режим | Когда | Как говорит Арвикс |
|---|---|---|
| 🟩 НОРМА | всё в порядке | требовательно, спокойно, конкретно |
| 🟦 ДАВЛЕНИЕ | выполнение < 50%, **хотя сон нормальный** | жёстко и коротко: «это выбор, а не усталость» |
| 🟨 ЖЁЛТЫЙ | сон < 6 ч два дня подряд или выполнение 20–40% | твёрдо, но без давления, план урезан |
| 🟥 КРАСНЫЙ | сон < 5 ч три дня, выполнение < 20% неделю или «сегодня без сил» | ментор выключен, долг заморожен, напоминаний о задачах нет, человеческий тон, без цифр |

В 🟥 жёсткие формулировки **физически не попадают** в промпт модели — это проверено тестом,
а не обещано на словах. Нет данных о сне — нет и «давления»: нельзя сказать «ты выспался»,
не зная этого.

**Как выйти из 🟥.** Красный — день восстановления, а не ловушка:
- выспался — напиши сон («лёг в час, встал в 8:30»): если 🟥 был из-за недосыпа, режим пересчитается сразу;
- готов вернуться — нажми **▶️ Вернуться к плану** на панели (или скажи «режим восстановился» — Арвикс покажет
  кнопку): до утра режим не выше 🟨, план возвращается без разгона;
- дни в 🟥 провалом не считаются и 🟥 не продлевают.

### 7.4. Safety-контур
Если в сообщении признаки настоящей беды (а не «устал»), бот сразу:
- выключает режим ментора;
- переходит на человеческий тон без задач и цифр;
- советует написать живому человеку (тому, кого ты назвал в вопросе 47); при угрозе
  жизни — 112.

Обратно ментор включается **только тобой**: `/mentor on` или `arvix mentor on`.
Ни Claude, ни модель включить его не могут — такого инструмента нет.

### 7.5. Долг
Провалил задачу важности 4–5 — она уходит в долг и висит в брифинге. Пока в долге
2+ задачи, новые необязательные дела (сфера `social`) **блокируются** — кроме 🟥: там живые
люди — часть восстановления. Долг закрывается
выполнением или списывается с письменным обоснованием (в Claude Code: «спиши долг,
потому что…»).

### 7.6. Квоты недели
Недельные минимумы: спорт 3, социум 2, новое 1, отдых без экрана 3. Со среды
незакрытые квоты подсвечиваются в брифинге, в воскресенье проверяются. Живая встреча
засчитывается в квоту, если сказать о ней в чате («виделся с Тимуром») или записать
задачей в сфере `social`.

### 7.7. Протокол игнора — если ты пропал

| День молчания | Что делает бот |
|---|---|
| 1 | обычные напоминания, вечером: «Ты сегодня молчишь. Что происходит?» |
| 2 | только брифинг и разбор, тон жёстче |
| 3 | одно сообщение, **долг заморожен** |
| 4–8 | одно сообщение в день: «Я здесь.» |
| 9+ | «Я здесь.» раз в неделю, пока не вернёшься |
| возврат | без «Я здесь.» и без стены напоминаний: брифинг, разбор, один вопрос «что случилось» и один маленький шаг; разбор прошлого — не раньше чем через 3 дня |

### 7.8. Тихий день
`/silent` — бот молчит до вечера, ты ведёшь день сам, долга за день нет. Можно сделать
тихий день автоматическим раз в неделю (раздел 9.2).

### 7.9. Сократовский режим
На учебный вопрос Арвикс не даёт готовый ответ: направление, наводящий вопрос,
2–3 источника (первоисточник — первым: учебник с параграфом, демоверсия ФИПИ, документация;
ссылка — только настоящая), «20 минут сам, потом объяснишь мне». Не учебное — план, поиск
в заметках, настройка — помогает прямо.
Если ответ уже есть в твоих заметках — отправит к заметке. Готовый ответ — после `/answer`
(это пишется в журнал). Роадмапы — в папке предмета (`02_Areas/<Предмет>/`) или в `03_Resources/Роадмапы/`.

---

### 7.10. Арвикс не верит на слово
Ты можешь ошибиться: поставить цель, которая тебе не нужна, план, который не выполнить, задачу поверх школы,
отметить полуторачасовой блок через 20 минут. Арвикс не продолжает молча:
- **код проверяет** каждую цель (срок, метрика, дубль, лишняя цель года, срок дальше трёх лет — это мечта),
  задачу (внахлёст, на школе, впритык к отбою, длиннее трёх часов, время уже прошло), отчёт («стоит на 18:00, а
  отмечена в 10:00») и сон («15 часов — опечатка?»);
- **модель называет** несостыковку первой строкой, объясняет цифрами — твоими часами, сном, выполнением, главной
  целью — и **исправляет сама**: мечта вместо цели, срок и метрика, меньший блок, другое время. Говорит, что
  изменила и как вернуть. Если исправление меняет смысл — даёт готовый вариант и ждёт одно «да»;
- старые несостыковки (цель без срока с первого дня) Арвикс поднимает сам, даже если ты спросил о другом.

Пример: «Новая цель — японский N2 к лету» при ОГЭ в мае и 10 часах в неделю. Ответ: целью года не записываю —
провалятся обе; записал мечтой, ступень после экзаменов — «хирагана и катакана к 1 августа». Хочешь японский
важнее ОГЭ — скажи.

Сомнение не запрещает запись: отчёт записан, но с пометкой — её увидит вечерний разбор. В 🟥 проверок нет.

## 9. Настройка под себя

Всё, кроме профиля, живёт в `~/.config/arvix/config.toml`. Правь его в любом редакторе,
после правки — `systemctl --user restart arvix-telegram`.

### 9.1. Полный пример конфига
```toml
timezone = "Europe/Moscow"
vault = "/home/dastan/Документы/Obsidian Vault"
home = "/home/dastan/Arvix"

[telegram]
token = "…"                       # пишет arvix setup --telegram
owner_id = 123456789

[vault_paths]                     # где в хранилище файлы Арвикса; setup находит сам, можно поправить
roadmaps = "02_Areas/Роадмапы"
inbox = "00_Inbox/Входящие.md"
daily_template = "05_System/Templates/Daily Report.md"
# profile, goals, notes, weekly, system — по умолчанию в 05_System/… и 03_Resources/…

[remote]                          # только если бот и журнал живут на сервере (раздел 10)
host = "arvix@HOST"

[schedule]
brief = "auto"                    # auto = подъём из профиля + 15 мин, или "07:30"
midday = "15:00"
debrief = "22:30"
retro_weekday = 6                 # 0 = пн … 6 = вс
retro = "20:00"
rollover = "04:00"                # до 04:00 вчерашний день ещё открыт для отчётов
bedtime_warning_min = 30
silent_weekday = -1               # например 6 = каждое воскресенье тихий день

[brain]
claude_bin = "/home/dastan/.npm-global/bin/claude"
timeout_sec = 180
vault_tools = true                # голова может читать хранилище (Read/Grep/Glob)

[roles.voice]                     # ответы в чате
model = "sonnet"
[roles.analyst]                   # разбор и ретро
model = "sonnet"

[mechanics]
sleep_target_min = 450            # 7.5 ч
deep_target_min = 120             # глубокая работа в день
week_budget_min = 1560            # 26 ч продуктивного времени в неделю
week_deep_budget_min = 480        # из них 8 ч глубокой работы
shields_per_month = 2

[mechanics.quotas]
sport = 3
social = 2
novelty = 1
offscreen = 3
```
Учти: `arvix setup` перезаписывает файл и удаляет из него комментарии. Значения сохраняются.

### 9.2. Расписание
- Будильник и брифинг: время подъёма берётся из профиля (вопрос 4), брифинг приходит
  через 15 минут. Фиксированное время: `brief = "07:30"`.
- Сова и ложишься в 2 ночи: сдвинь `rollover = "05:00"` — до этого времени можно
  отчитаться за вчера.
- Тихий день раз в неделю: `silent_weekday = 6` (воскресенье).

### 9.3. Модели и расход подписки
«Голова» — это `claude -p` по твоей подписке **Pro**, лимит общий с обычной работой
в Claude Code.
- Экономнее и быстрее: `[roles.voice] model = "haiku"`.
- Умнее разбор и ретро: `[roles.analyst] model = "opus"` (на Pro расходует лимит быстрее).
- Лимит кончился — бот отвечает шаблоном. Кнопки, напоминания, долг и режим работают дальше,
  потому что им модель не нужна.

Примерный расход: одно сообщение в чат — один вызов (~2–5 тысяч токенов), разбор — один-два,
ретро — один в неделю.

### 9.4. Шаблоны дней — главное, что делает план «твоим»
Из шаблона каждое утро создаются задачи. Тип дня: `study` (учебный), `work` (смена),
`deep` (глубокий), `recovery` (восстановление), `silent` (тихий).

Проще всего настроить словами в Claude Code (в `~/Arvix`):
> «Пн–чт у меня колледж до 14:00. Сделай учебные дни: 16:00 алгоритмы 90 минут глубокой
> работы, 19:00 английский 30 минут. Пт–вс смены до 20:00 — один блок 21:00 на 40 минут.»

Claude покажет шаблоны, ты подтвердишь — они сохранятся. Поменять — тоже словами:
«в среду вместо английского зал в 18:00».

Поля блока: время начала, длительность, название, сфера (`learning`, `work`, `sport`,
`social`, `health`, `finance`, `project`, `chore`), важность 1–5, сложность 1–5, глубокая
работа да/нет, теги (`novelty` — новое, `offscreen` — отдых без экрана, считаются в квоты).

**Обязательное** (школа, дорога, смена, репетитор) — блок с `fixed: true`: это занятое время.
Задачей оно не становится — ни напоминаний, ни «Сделано?», ни отчёта, ни долга. Арвикс знает,
что ты занят (строка ЗАНЯТО), и ничего туда не ставит. Таблица распорядка показывает длительность твоих
блоков так, как её поставит автонагрузка: «90→65 мин».

Чем выше важность, тем строже подтверждение и больнее провал. Ставь 4–5 только тому,
что правда критично.

### 9.5. Характер Арвикса
Голос задан файлами в `arvix-claude/arvix/constitution/`:

| Файл | Что задаёт |
|---|---|
| `identity.md`, `mission.md` | кто он и зачем |
| `voice.md` | как говорит: коротко, с цифрами, без лести, максимум один вопрос |
| `autonomy_rule.md` | сократовский режим |
| `decision_rule.md` | просьба изменить план — сделка: цена в цифрах и вариант, решаешь ты |
| `honesty.md`, `boundaries.md`, `safety_override.md` | честность, границы, безопасность |
| `tone_norm.md` / `tone_pressure.md` / `tone_yellow.md` / `tone_red.md` | тон в каждом режиме |
| `fewshot.json` | 8 примеров «ситуация → ответ Арвикса» |
| `channel_telegram.md` | правила для Telegram и формат ответа модели |

Если Арвикс звучит не так — **правь примеры в `fewshot.json`**, а не правила: характер
лучше передаётся примерами. Пример с `"harsh": true` в 🟥 не попадёт в промпт.

После правки:
```bash
cd ~/"Рабочий стол/Projects/Arvix/arvix-claude"
python3 scripts/build_assets.py
python3 -m unittest discover -s tests -t .
bash deploy/install.sh
```
Первая команда пересобирает стиль для Claude Code из конституции, вторая проверяет,
что в 🟥 жёсткий тон по-прежнему отсекается, третья копирует обновление и перезапускает бота.

### 9.6. Память о тебе
Скажи в Claude Code или в Telegram: «запомни: после смены я ничего не могу» — факт
сохранится и будет подставляться в контекст. Посмотреть всё, что Арвикс о тебе знает:
«покажи мой профиль» или `05_System/Профиль Арвикса.md` после экспорта. Забыть: «забудь факт про …».

### 9.7. Твой ежедневный отчёт в Obsidian
Арвикс читает твою ежедневную заметку из `08_Daily Report/` (папку берёт из настроек
Obsidian) и поля frontmatter: `energy`, `focus_minutes`, `wake`, `sleep`, `workout`…
Заполнил отчёт — в брифинге и разборе Claude использует эти данные, а не переспрашивает.
Отчёт дня создаётся **по твоему шаблону** при утреннем брифинге: дата, номер дня и недели,
задачи чекбоксами. Шаблон берётся из настроек Obsidian (Daily notes → Template); если там
путь в пустоту, `arvix setup` находит файл в папке шаблонов (у тебя —
`05_System/Templates/Daily Report.md`) и пишет его в `[vault_paths] daily_template`.
Вечером после разбора Арвикс заполняет только **пустые** поля, и только те, что есть в твоём
шаблоне (`focus_minutes`, `sleep`, `wake`, `workout`), и вписывает итоги и разбор в свой блок
`<!-- arvix:день -->`. Что ты написал сам — не трогается.

### 9.8. Как Арвикс пишет в хранилище
Отдельной папки нет — он работает в твоей структуре:

| Что | Куда |
|---|---|
| профиль | `05_System/Профиль Арвикса.md` |
| цели | `05_System/Цели/` |
| роадмапы | папка предмета в `02_Areas/` или `02_Areas/Роадмапы/` (нашёл `setup`) |
| каркасы конспектов | `02_Areas/<Предмет>/Конспекты/` или `03_Resources/Обучение/` |
| ретро недель | `05_System/Недели/` |
| Inbox | `00_Inbox/Входящие.md` (нашёл `setup`) |
| журнал событий, выводы, бэкапы | `05_System/Арвикс/` |
| ежедневные отчёты | `08_Daily Report/` (из настроек Obsidian) |

Места меняются в `[vault_paths]` конфига (`arvix setup` подставляет найденные, но не трогает
то, что ты записал сам). Правила записи зашиты в код:
- свои новые заметки создаёт где угодно;
- твои — только дописывает в конец или обновляет свой блок `<!-- arvix:… -->`;
- перезаписать твою заметку (или свою, которую ты поправил) — только после твоего явного «да», и сначала сохранит копию в `05_System/Арвикс/_backup/`;
- удалять не умеет вообще.

### 9.9. Автонагрузка — без выгорания и без ручных настроек
Сколько глубокой работы, учёбы, спорта и отдыха — решаешь не ты, а код (`arvix/load.py`, без ИИ).
- **Каналы:** глубокая работа, учёба, спорт, отдых, прочее. У каждого свой коэффициент к блокам шаблона.
- **Обязательное не трогается и задачей не становится:** школа, дорога, репетитор, секция
  (`fixed` в шаблоне или очевидное название). Бюджет недели — только твоё время.
- **Старт — 70%** от твоего распорядка для самостоятельной работы: люди переоценивают силы.
- **Раз в неделю** код смотрит выполнение по каждому каналу, сон и дни 🟨/🟥:
  - признаки выгорания (🟥 2+ дня, 🟨 3+ дня, недосып > 1 ч) — **сразу −20% работы, +20% отдыха**;
  - первые признаки усталости — −10% / +10%;
  - канал выполнен < 50% — **−15%** этому каналу: план не по силам;
  - канал ≥ 85% **две недели подряд** — **+10%**;
  - 50–85% — ничего не меняется: один плохой день план не дёргает;
  - меньше 4 дней с задачами — держим.
- Коэффициенты от 0.5 до 1.5. Перемена приходит одной строкой в утреннем брифинге с причиной.
- **Предупреждения сразу**: неделя больше бюджета, день больше разумного максимума, глубокой работы больше 4 ч,
  блок впритык к отбою.

### 9.10. Голосовые сообщения
Отправь голосовое — бот распознает и ответит по делу, расшифровку не показывает: что он понял, видно по строке
«что записано» под ответом. Хочешь видеть текст — `show_transcript = true` в секции `[stt]` конфига.
Если распознал неправильно — просто поправь следующим сообщением. По умолчанию голосовые выключены: `claude -p`
звук не понимает, нужен распознаватель. Настраивать там, где работает бот (у тебя — на сервере).

**Groq — бесплатно и быстро** (голос уходит в Groq). Ключ: console.groq.com → API Keys → Create.
```bash
ssh -t arvix@HOST '~/.local/bin/arvix setup --stt groq --yes && systemctl --user restart arvix-telegram'
```

**Локально — приватно, без ключа** (медленнее, на одном ядре 10–20 секунд на полминуты речи):
```bash
ssh -t arvix@HOST 'bash ~/.local/share/arvix/app/deploy/stt-local.sh base'
ssh -t arvix@HOST '~/.local/bin/arvix setup --stt command --yes && systemctl --user restart arvix-telegram'
```
Если скрипт попросит пакеты: `sudo apt install -y git cmake g++ ffmpeg` под root. Проверка — `arvix doctor`.
Голосовое длиннее 5 минут бот попросит разбить.

### 9.12. Учебный блок
Задача сферы «учёба» (физика, математика, Python) — это урок, а не бронь времени. Когда блок начинается (или ты жмёшь
`▶️`, `🎯` или «давай позанимаемся физикой»), Арвикс читает твой роадмап, журнал ошибок и заметки о методе, берёт следующую тему и присылает
план по минутам: вспомнить с пустого листа → учебник с параграфом или выжимка в NotebookLM → задачи на Решу ОГЭ →
заметка своими словами в Obsidian (каркас по твоему шаблону Concept он создаёт сам) → проверка. Жмёшь «Начать» —
идёт таймер. Застрял — спроси в чате: внутри блока он объясняет по шагам с примером, но задачу за тебя не решает.
Когда время вышло, приходят 3 вопроса — ответ одним сообщением (можно голосом) и есть отчёт: оценка идёт в
выполнение задачи, пробелы — строкой «в карточки и журнал ошибок». «Физика 30 минут» — блок прямо сейчас.
Выключить: `auto_lesson = false` в секции `[learning]` конфига.

### 9.11. Кнопки, панель дня и фокус-таймер
- **Кнопки внизу** (`📋 День` · `✅ Сделал` · `🎯 Фокус` / `😴 Сон` · `➕ Задача` · `📊 Итоги` / `📱 Приложение`)
  приходят с утренним брифингом.
- **Панель дня** — закреплённое сообщение сверху чата: сколько сделано, режим, задачи и у каждой кнопки
  `▶️` начать · `✅` сделал · `⏳ 30` отложить (у идущей — `✅` и `⚠️ частично`). Панель обновляется сама: отметил
  задачу в приложении, в Claude Code или в терминале — через несколько секунд это видно в Telegram.
- **Фокус** (`🎯` или «засеки 45 минут») запускает ближайшую задачу и считает минуты прямо в сообщении; `⏹ Стоп`
  записывает прошедшее (меньше 5 минут — сброс). Если таймер покрыл хотя бы половину блока, это видно в журнале при
  закрытии задачи — отчёт одной фразой всё равно нужен.
- **Ответы** приходят короткими сообщениями, как от человека: каждое предложение с новой строки, главное — **жирным**.
  Под ними отдельной строкой — что реально записано. Одним сообщением — `bubble_pause_sec = 0` в `[telegram]`.
- **Первое сообщение за день** Арвикс начинает с приветствия, поздно вечером — прощается. Раз в день (18:30,
  `[schedule] curiosity`) пишет первым: спрашивает про то, что помнит, — пробник, разговор, решение.

### 9.13. Приложение: Telegram, телефон, терминал
Одно приложение в трёх местах, обновляется само — отметил задачу в чате, она тут же отмечена везде.

- **В Telegram** — кнопка «Арвикс» слева от поля ввода или `📱 Приложение` внизу. Вкладки: Сегодня (цифры, таймер,
  план, «+» — задача), Арвикс (весь разговор, голосовое с микрофона), Заметки (хранилище, поиск, «Мысль в Inbox»),

- **На телефоне** — в приложении «Прогресс → Установить на телефон», откроется Chrome, там ⋮ → «Установить
  приложение». Chrome соберёт настоящее Android-приложение (APK) с иконкой Арвикса.
- **На ноутбуке** — просто `arvix` в терминале: слева день, справа разговор, внизу строка ввода. ↑/↓ — задача,

Включить на сервере (один раз, с ноутбука): `bash deploy/web-setup.sh root@109.120.130.46`. Скрипт ставит Caddy,

### 9.15. Проекты
Вкладка «Проекты» — то, что ты строишь сам: бот, сайт, канал, подкаст, исследование, мероприятие. Арвикс не делает
проект за тебя — режет на шаги, ставит время, подсказывает источники, проверяет результат и не даёт бросить.

1. **«+ Проект»**: название, *что это* (подсказки или своё слово), *зачем* — сколько угодно причин (навык, портфолио,
   люди, поступление… или своя), *ожидание* — проверяемый результат, цель, срок, часы в неделю, навыки, ссылка,
   репозиторий, первый этап. Или словами в чате: «хочу сделать бота расписания к Новому году, 3 часа в неделю».
2. **«Из GitHub»**: один раз — ник; дальше список твоих репозиториев: «Проект» создаёт проект из репозитория, в
   проекте — «Привязать». Коммиты Арвикс сам забирает раз в час: они считаются движением проекта и идут в портфолио.
   Приватные репозитории — токен в конфиге сервера: `[github] token = "…"` (в чат его не присылай).
3. **«Роадмап»** — проекты по целям, по порядку (↑↓). **«Роадмап от Арвикса»** у цели — Арвикс за минуту-две
   предложит 3–6 проектов от простого к сложному с этапами и источниками. Они лягут идеями; в работу берёшь сам
   («В работу»). Заметка — в папке роадмапов: `Проекты — <цель>`.
4. **Окно Арвикса** в проекте: «Какой следующий шаг?», «Разложи на этапы», «Проверь, готов ли этап» — или свой
   вопрос. Он видит этапы, время, коммиты и источники проекта и может сам поставить блок или этап.
5. **Этапы** — у каждого «готово, когда…». **«Блок в план»** — первое свободное окно, напоминание как у задачи.
6. **Источники и инструменты** — документация, курсы, видео, Figma, чат команды, заметка из хранилища — открываются
   одним нажатием. Предложенные Арвиксом помечены «проверь».
7. **Люди и трафик** — откуда приходят пользователи и единомышленники: гипотеза → охват → отклики → пришли.
8. **«В Obsidian»** — карточка для портфолио в `01_Projects/<название>.md`. Твой текст в заметке не трогается.

Денег в проектах нет: доход с заказов, самозанятости, крипты честно не посчитать. Правила кода: в работе не больше 3
проектов; неделя без движения — Арвикс напишет сам; три недели — спросит прямо: продолжаем, пауза или закрываем.

## 10. Арвикс на сервере (VPS)

Бот пишет круглосуточно, даже когда ноутбук закрыт. Сервер вне России — VPN для головы не нужен.

**Как устроено:**
- журнал событий живёт **только на сервере** (`~/.local/share/arvix/arvix.db` пользователя `arvix`);
- ноутбук в **удалённом режиме**: секция `[remote]` в `~/.config/arvix/config.toml` — и MCP-сервер,
  и хук, и команда `arvix` запускаются на сервере по SSH (`arvix/remote.py`). Скиллы те же, база одна;
- хранилище Obsidian синхронизирует `rsync` по таймеру раз в 10 минут в обе стороны (ноутбук ⇄ `~/vault`
  на сервере); Syncthing — по желанию, он надёжнее при одновременных правках;
- голова — `claude -p` на сервере по токену подписки из `claude setup-token` (`~/.config/arvix/claude.env`, права 600).

### 10.1. Подготовка сервера (один раз, под root)
```bash
ssh root@HOST 'PUBKEY="'"$(cat ~/.ssh/id_ed25519.pub)"'" bash -s' < arvix-claude/deploy/server-setup.sh
```
Скрипт ставит python3, rsync, sqlite3, syncthing; создаёт пользователя `arvix` с linger
(его службы живут без входа), кладёт ключ ноутбука в `authorized_keys` и ставит Claude CLI
под `arvix`. Если сервер переустанавливали, ssh откажет с `REMOTE HOST IDENTIFICATION HAS CHANGED`:
убери старый отпечаток `ssh-keygen -R HOST` и подключись вручную, подтвердив новый.

### 10.2. Арвикс на сервер (с ноутбука)
```bash
bash arvix-claude/deploy/sync-server.sh arvix@HOST --init
```
`--init` переносит конфиг ноутбука (тот же токен бота, часовой пояс, `[vault_paths]`)
с серверными путями: `vault = ~/vault`, `home = ~/Arvix`, `claude_bin = ~/.local/bin/claude`.
Дальше скрипт запускает там `install.sh`, `init-home` и `doctor`.

Один раз, с ноутбука, в интерактивном терминале (нужен браузер для входа в аккаунт):
```bash
ssh -t arvix@HOST bash ~/.local/share/arvix/app/deploy/server-claude-token.sh
```
Скрипт запускает `claude setup-token`, кладёт токен подписки в `~/.config/arvix/claude.env`
(права 600, на экран не выводит) и перезапускает бота. Потом на сервере:
`systemctl --user enable --now arvix-telegram`.

Хранилище: таймер `arvix-vault-sync.timer` на ноутбуке раз в 10 минут гоняет `rsync` в обе
стороны (новее побеждает, ничего не удаляется) между хранилищем и `/home/arvix/vault`.
Ограничения `rsync`: удаления и переименования не переносятся, а если ты правишь заметку в те же
10 минут, когда бот дописывает её на сервере (заметка дня около разбора, Inbox), побеждает более
свежий файл целиком. Syncthing сохраняет обе версии — переходи на него, если правишь хранилище
вечером активно.

### 10.3. Ноутбук — в удалённый режим
```bash
arvix remote set arvix@HOST                          # проверит ssh и запишет [remote] в конфиг
systemctl --user disable --now arvix-telegram        # два бота с одним токеном мешают друг другу
systemctl --user enable --now arvix-vault-sync.timer # хранилище ⇄ сервер каждые 10 минут
systemctl --user enable --now arvix-backup.timer     # копия журнала раз в сутки
```
Теперь команда `arvix`, MCP-сервер в Claude Code/Desktop и хук ходят на сервер по SSH;
строка состояния кэшируется на минуту. `arvix remote show` — где журнал, `arvix remote off` —
обратно в локальный режим. `ARVIX_LOCAL=1 arvix …` — принудительно локально.
`setup`, `init-home`, `doctor`, `desktop-mcp` всегда работают на этой машине.

### 10.4. Бэкапы
- ноутбук: `arvix-backup.timer` раз в сутки забирает целостный снимок базы
  (`sqlite3 .backup`) в `~/.local/share/arvix/backups/`, 14 копий; хост берётся из `[remote]`.
  Вручную: `bash ~/.local/share/arvix/app/deploy/arvix-backup.sh`;
- сервер: cron в 04:30 — копия по дню недели в `~/backups/` (7 копий):
  `30 4 * * * sqlite3 ~/.local/share/arvix/arvix.db ".backup ~/backups/arvix-$(date +\%u).db"`.

### 10.5. Обновление
```bash
bash arvix-claude/deploy/sync-server.sh arvix@HOST   # сервер: код, install.sh, перезапуск бота
bash arvix-claude/deploy/install.sh                  # ноутбук: плагин и CLI
```
Логи бота: `ssh arvix@HOST journalctl --user -u arvix-telegram -f`.

## 12. Данные, бэкап, приватность

| Что | Где |
|---|---|
| журнал (вся история) | `~/.local/share/arvix/arvix.db` |
| конфиг и токен бота | `~/.config/arvix/config.toml` (права 600) |
| профиль, цели, роадмапы, Inbox | твоя структура хранилища (раздел 9.8) |
| полный журнал текстом | `05_System/Арвикс/Журнал событий.md` после экспорта |

**Бэкап:** `arvix export` (или `/export`) выгружает всё в Obsidian. Если хранилище
синхронизируется, бэкап получается автоматически. Для полной копии базы:
```bash
cp ~/.local/share/arvix/arvix.db ~/arvix-backup-$(date +%F).db
```

**Что уходит наружу:**
- в Anthropic — текст сообщений и контекст дня при каждом вызове «головы»;
- в Telegram — переписка с ботом.

Остальное хранится только локально. Токен бота не попадает ни в git, ни в промпты.

Удаление плагина (`claude plugin uninstall arvix@arvix`) журнал **не удаляет**: данные
лежат отдельно специально.

## 13. Если что-то сломалось

| Симптом | Что делать |
|---|---|
| Бот не отвечает | `systemctl --user status arvix-telegram`, потом `journalctl --user -u arvix-telegram -n 50` |
| «Голова сейчас недоступна» | кончился лимит подписки или нет сети; `arvix brain-test` покажет, отвечает ли Claude |
| В Claude Code спрашивает разрешение на каждый инструмент | папке `~/Arvix` не дали доверие — запусти `claude` там интерактивно и ответь «да» |
| Нет стиля Arvix | сессия открыта не в `~/Arvix`; или `/output-style arvix:Arvix` |
| Нет задач и напоминаний | не настроены шаблоны дней (раздел 9.4) |
| Режим «застрял» в 🟥 | возможно, выключен ментор: `/status`, вернуть — `/mentor on`; SOS снимается `/sos off` |
| Сомнения в цифрах | `arvix rebuild` — проверка, что пересчёт журнала совпадает с текущим состоянием |
| Обновил код в репозитории | `bash arvix-claude/deploy/install.sh` — скопирует и перезапустит бота |
| Строка состояния пустая или с ошибкой | `echo '{}' \| arvix statusline` покажет причину; в удалённом режиме «сервер недоступен» — проверь `ssh HOST` |
| `ssh`: REMOTE HOST IDENTIFICATION HAS CHANGED | сервер переустановлен или подменён: убедись, что это твой сервер, `ssh-keygen -R HOST`, подключись вручную |
| Общая проверка | `arvix doctor` |

## 14. Ограничения

- На ноутбуке бот молчит, пока ноутбук спит; на сервере — круглосуточно (раздел 10).
- Пока голова думает над сообщением (до 3 минут), напоминания ждут: бот работает в один поток.
- Фото-отчёт принимается без проверки: трение и ритуал, а не верификация.
- Поиск по заметкам — по словам и их основам, без векторного поиска; на сотнях заметок
  этого хватает.
- Голова на сервере видит всё хранилище — не держи там пароли и чужие личные данные.
- Синхронизация хранилища `rsync`: удаления не переносятся, окно конфликта 10 минут (раздел 10.2).
- Голосовые требуют распознавателя: Groq (голос уходит туда) или локальный whisper.cpp (медленнее), раздел 9.10.
- Нет: веб-приложения в Telegram, связи с ESP32-таймером, данных с часов.
  Что и в каком порядке появится — `docs/08-ROADMAP.md`, почему чего-то не будет — `docs/09-DECISIONS.md`.
